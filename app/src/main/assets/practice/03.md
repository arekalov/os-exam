---
Планировщик на джава, каждый день в 0:00 проверяет, была ли рубежка в последние 2 недели, если была, то получает всех студентов, кто её писал, и от имени каждого студента посылает преподавателю по каждому предмету сообщение с интервалом 5 секунд для предотвращения атак. Использовать только стандартную библиотеку Java. 

```java
public class SimpleScheduler {
    private DbService dbService;
    private MailSender mailSender;

    // constructor должен быть здесь

    private final ScheduledExecutorService scheduler = Executors.newSingleThreadScheduledExecutor();

    public void scheduleNextMidnight() {
        LocalDateTime now = LocalDateTime.now();
        LocalDateTime nextMidnight = now.plusDays(1).withHour(0).withMinute(0).withSecond(0).withNano(0);
        
        long delayMillis = Duration.between(now, nextMidnight).toMillis();

        scheduler.schedule(() -> {
            runDailyTask();
            scheduleNextMidnight();
        }, delayMillis, TimeUnit.MILLISECONDS);
    
    }

    private void runDailyTask() {
        boolean hasSubmission = dbService.hasSubmissionsLastTwoWeeks(); 

        if (hasSubmission) {
            List<Student> students = dbService.getSubmittedStudentsLastTwoWeek();
            for (String student : students) {
                mailSender.sendPingMessage("tsopa@tune-it.ru", student.getMail());
                
                try {
                    Thread.sleep(5000); 
                } catch (InterruptedException e) {
                    Thread.currentThread().interrupt();
                    break;
                }
            }
        } 
    }

    public static void main(String[] args) {
        new SimpleScheduler().scheduleNextMidnight();
        
        // Держим программу запущенной
        Thread.sleep(Long.MAX_VALUE);
    }
}
```
