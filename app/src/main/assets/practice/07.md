title: Последовательность действий standalone-режиме Camunda на Wildfly
---
Описать последовательность действий для разворачивания в standalone-режиме Camunda на WildFly и деплоя процесса, описанного с помощью standalone-приложения Modeler

1. Скачать дистрибутив
Скачать camunda-bpm-wildfly-7.x.x.zip с camunda.com — это WildFly с уже встроенными модулями Camunda, распаковать.
2. Запустить WildFly `./bin/standalone.sh`
    - Проверить: http://localhost:8080/camunda (demo/demo)
3. Нарисовать процесс в Camunda Modeler
    1. Открыть Camunda Modeler (отдельное desktop приложение)
    2. Создать новый BPMN файл
    3. Нарисовать процесс
    4. Указать Process ID и Process Name
    5. Сохранить как process.bpmn
4. Задеплоить процесс (можно сделать 3 способами: через Modeler напрямую, через через Camunda Cockpit REST API, через папку deployments), рассмотрим последний сопособ: 
нужно Скопировать process.bpmn в:
wildfly/standalone/deployments/
WildFly подхватит автоматически
5. Проверить деплой: 
- Открыть http://localhost:8080/camunda/app/cockpit
- Убедиться что процесс появился в списке
- Запустить тестовый инстанс через Tasklist
