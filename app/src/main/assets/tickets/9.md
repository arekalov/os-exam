## Установка PostgreSQL
Есть 2 варианта установки: 
1. Через графический установщик
2. С использованием утилит:
   * Подготовленные бинары для разных ОС
   * Комиляция исходных кодов (make), если нет бинаря для ОС

С точки зрения postgres есть несколько базовых компонентов:
* сервер (postgresql)
* клиент (postgresql-client, psql, pgAdmin)
* вспомогательные компоненты (contrib, docs)
  
Этапы установки:
1. Установка (сборка) базовых коомпонентов: `sudo apt install postgresql postgresql-client`
2. Подготовка места для кластера данных, создание системного пользователя postgres
3. Задание переднных окружения (напримре, PGDATA)
4. Запуск скрипта initdb, с помощью которого создаются каталоги и подкаталоги кластера БД, стандартные БД (template0, template1), задание используемых локали и кодировки
5. Запуск экземпляра кластера БД (`postgres, pg_ctl start, sudo service postgresql start`)

Утилита **pg_ctl** - для упроащения взаимодействия с postgres:
* Можно запускать (`start`), перезапускать (`restart`), останавливать (`stop`) кластер
* Можно использовать для инициализации кластера (`pg_ctl initdb`)
