## JTA (Java Transaction API)

Стандартный API для управления распределёнными транзакциями в Jakarta EE.
- Входит в состав Jakarta EE (ранее Java EE)
- Реализует стандарт X/Open XA
- Контейнер содержит менеджер транзакций, управляющий ресурсами

Требует поддержки XA на уровне сервера приложений (DataSource) и JDBC-драйвера (XAResource). На несовместимых с XA драйверах распределённые транзакции не работают.

## Два режима управления в EJB

**BMT (Bean-Managed) — программный:**

Программист сам управляет через `UserTransaction`:

```java
utx.begin();
try { ...; utx.commit(); }
catch (Exception e) { utx.rollback(); }
```

**CMT (Container-Managed) — декларативный:**

Контейнер управляет через `@TransactionAttribute(TransactionAttributeType.REQUIRED)`.

## Spring JTA

Spring Boot поддерживает распределённые JTA-транзакции. Два варианта:

- Сервер приложений Jakarta EE с поддержкой JTA (WildFly, GlassFish)
- Встроенный менеджер транзакций: **Atomikos** (`spring-boot-starter-jta-atomikos`) или **Bitronix**

В Spring два режима как в Jakarta EE — программный и декларативный (`@Transactional`). По умолчанию используется менеджер транзакций ORM-фреймворка (Hibernate/JPA).
