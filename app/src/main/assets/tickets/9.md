## Что такое менеджер транзакций

Компонент, который управляет жизненным циклом транзакции: открывает, коммитит, откатывает. Абстрагирует прикладной код от конкретного ресурса.

## В Spring — PlatformTransactionManager

Интерфейс с тремя методами: `getTransaction`, `commit`, `rollback`.

Реализации:
- **`DataSourceTransactionManager`** — для JDBC
- **`JpaTransactionManager`** — для JPA/Hibernate; связывает транзакцию с EntityManager
- **`JtaTransactionManager`** — для распределённых XA-транзакций (JTA)

Spring Boot автоматически регистрирует нужный менеджер через auto-configuration. Если в classpath есть JPA — создаётся `JpaTransactionManager`.

## В Jakarta EE — TransactionManager / UserTransaction

- **`TransactionManager`** — API для контейнера (CMT)
- **`UserTransaction`** — API для приложения (BMT), инжектируется через `@Resource`

## Как Spring выбирает менеджер

`@Transactional` по умолчанию использует бин `transactionManager`. Можно указать явно:

```java
@Transactional("secondaryTxManager")
public void doSomething() { ... }
```
