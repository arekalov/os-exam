## Создание Базы Данных в PostgreSQL

**База данных** — изолированное пространство для хранения объектов (таблицы, схемы, функции). Все БД кластера разделяют процессы и разделяемую память, но физически хранятся в отдельных подкаталогах `PGDATA/base/<oid>`.

При создании PostgreSQL копирует файлы шаблонной базы и регистрирует новую БД в системном каталоге `pg_database`.

### Команда создания
```sql
CREATE DATABASE имя
    OWNER = роль
    TEMPLATE = шаблон
    ENCODING = кодировка
    LC_COLLATE = локаль_сортировки
    LC_CTYPE = локаль_символов
    TABLESPACE = табличное_пространство
    CONNECTION LIMIT = лимит;
```

Через утилиту: `createdb -U postgres -O owner -E UTF8 mydb`

### Параметры
* **OWNER** — роль-владелец БД, по умолчанию текущий пользователь.
* **TEMPLATE** — шаблон (по умолчанию `template1`). Для нестандартной кодировки используют `TEMPLATE template0`.
* **ENCODING** — кодировка символов (UTF8, SQL_ASCII). Должна быть совместима с локалью.
* **LC_COLLATE / LC_CTYPE** — локаль для сортировки и классификации символов. Задаётся только при создании, изменить нельзя.
* **TABLESPACE** — табличное пространство по умолчанию для объектов этой БД.
* **CONNECTION LIMIT** — максимум одновременных подключений (-1 = без ограничений).

### Просмотр и удаление
```sql
SELECT datname, encoding, datcollate FROM pg_database;
\l          -- в psql
DROP DATABASE mydb;  -- нельзя удалить БД с активными подключениями
```
