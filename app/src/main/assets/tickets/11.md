## Что такое JAAS

Стандартный API сервиса информационной безопасности, входит в Java SE (с Java 1.3).

- Для сисадмина — набор конфигурационных файлов
- Для программиста — API для проверки ролей и полномочий

Суть: определить *кто* запрашивает доступ и *может ли* он его получить.

## Основные объекты

- **Subject** — субъект аутентификации, носитель прав, источник запроса
- **Principal** — представление субъекта с некоторой точки зрения (имя, роль, сертификат)
- **Credential** — то, чем субъект подтверждает личность (пароль, токен, сертификат)

## Конфигурационные файлы

- **`*.login.conf`** — определяет, какие Login Module'и использовать
- **`*.policy`** — определяет привилегии пользователей или программ

## Login Module

API для аутентификации и авторизации. Двухфазный: login → commit (или abort).

5 методов:
- `initialize` — инициализация
- `login` — фаза 1: проверка credentials
- `commit` — фаза 2: добавление Principal'ов в Subject при успехе
- `abort` — откат при неудаче фазы 1
- `logout` — удаление информации субъекта

## Использование

В Jakarta EE сервер использует JAAS для защиты EJB и Servlet. Spring Security интегрируется с JAAS через `JaasAuthenticationProvider`.
