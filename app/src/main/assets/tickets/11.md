## Camunda
**Camunda** — платформа для автоматизации бизнес-процессо (Workflow Automation), реализующая нотацию BPMN 2.0 для моделирования и исполнения процессов. Она предоставляет открытый движок (Java), средства для мониторинга и возможность оркестрации микросервисов (особенно в версии Camunda 8), сочетая асинхронную обработку сообщений с долгоживущими бизнес-транзакциями. Большинство процессных вещей, которые можно сделать в BPMN, делать в чистом
коде дороже в десятки раз

## Особенности и возможности
* Поддержка основных элементов BPMN 2.0 из коробки: User Task, Service Task, подпроцессы, события-таймеры, сигналы, сообщения, компенсирующие события для Saga
* 2 архитектурные эпохи:
  * Camunda 7 работает как встраиваемая библиотека внутри вашего Java-приложения и управляет процессами через транзакционное хранилище в SQL.
  * Camunda 8, облачная, построена на горизонтально-масштабируемом движке Zeebe, использует протокол gRPC, концепцию «External Task» и хранит журнал событий в распределенном логе.
* Поддержка из коробки REST API вызовы, отправка/получение сообщений через JMS, Kafka, RabbitMQ, работа с электронной почтой, файловыми системами и JDBC-источниками данных, что позволяет связывать BPMN-процессы с внешними системами без написания Java-кода.

### Основные компоненты
* Modeler — приложение для создания моделей BPMN процессов, нужных для других частей системы.
* Task list — веб-приложение, в котором исполнители выполняют задачи, поставленные на них бизнес-процессом, а также предоставляет исполнителям фильтрацию, сортировку, формы для заполнения данных, механизмы claim - захват задачи пользователем и assign - назначение в группу
* BPMN Engine — непосредственно движок, отвечающий за интерпретацию BPMN в объекты JAVA, сохранение объектов в базе и реализацию других вещей (типа листенеров активностей), которые крутятся вокруг процессов.
* DMN Engine — аналог BPMN Engine для DMN.
* Cockpit - веб приложение для просмотра состояния процессов, показывает диаграмму процесса с наложенным «зеленым токеном», позволяет исправлять инциденты, обновлять версии процессов «на лету» и выполнять миграцию запущенных экземпляров на новую модель. 
* Admin - веб приложение для управления пользователями и правами доступа
* Optimize - (платное) приложение для анализа и оптимизации бизнес-процессов, строит дашборы, SLA-отчеты на основе истории выполненных процессов
