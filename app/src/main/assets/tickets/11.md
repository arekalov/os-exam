## Propagation — поведение при вложенных транзакциях

- **REQUIRED** (по умолчанию) — присоединяется к существующей или создаёт новую
- **REQUIRES_NEW** — всегда создаёт новую, существующую приостанавливает
- **NESTED** — вложенная (savepoint внутри существующей), откат не откатывает внешнюю
- **SUPPORTS** — использует существующую если есть, иначе без транзакции
- **NOT_SUPPORTED** — без транзакции, существующую приостанавливает
- **MANDATORY** — требует существующей, иначе исключение
- **NEVER** — требует отсутствия транзакции, иначе исключение

## Isolation — уровень изоляции

- **DEFAULT** — уровень изоляции по умолчанию из БД
- **READ_UNCOMMITTED** — грязное чтение
- **READ_COMMITTED** — только зафиксированные данные
- **REPEATABLE_READ** — повторное чтение даёт тот же результат
- **SERIALIZABLE** — полная изоляция

## Остальные параметры

- **`readOnly`** — `true` оптимизирует под чтение (Hibernate не сбрасывает dirty check)
- **`timeout`** — таймаут в секундах, по истечении откат (по умолчанию -1 — без лимита)
- **`rollbackFor`** — массив классов исключений, вызывающих откат
- **`noRollbackFor`** — массив классов исключений, при которых откат не происходит
- **`rollbackForClassName`** / **`noRollbackForClassName`** — то же, через имена классов

```java
@Transactional(
    propagation = Propagation.REQUIRES_NEW,
    isolation = Isolation.READ_COMMITTED,
    readOnly = false,
    timeout = 30,
    rollbackFor = {BusinessException.class}
)
public void transfer(long from, long to, long amount) { ... }
```
