title: Выбор тестового покрытия с помощью диаграммы состояний и таблицы переходов.
---

**Тестирование на основе состояний** — для систем, поведение которых зависит от текущего состояния и событий.

**Диаграмма состояний:**
* **Состояние** — устойчивое условие системы (Ожидание, Активен, Заблокирован)
* **Переход** — смена состояния по событию: событие / [условие] / действие

**Таблица переходов** — табличная форма той же модели:

| Текущее | Событие | Следующее | Действие |
|---------|---------|-----------|----------|
| S0 | login | S1 | создать сессию |
| S1 | logout | S0 | удалить сессию |

**Критерии покрытия:**
1. Каждое **состояние** посещено
2. Каждый **переход** выполнен (основной критерий)
3. Все значимые **пути** (для критичных сценариев)

**Шаги:** выделить состояния → события → построить модель → тесты на все переходы + негативные (недопустимое событие в состоянии).
