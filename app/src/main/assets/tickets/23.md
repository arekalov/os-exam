## Подключение и конфигурация

В Spring Boot подключается `spring-boot-starter-data-rest` и модуль доступа к данным, например `spring-boot-starter-data-jpa`. Репозитории и сущности обнаруживаются при сканировании приложения.

Базовый путь задаётся в `application.properties`:

```properties
spring.data.rest.base-path=/api
```

Программные настройки выполняются через **`RepositoryRestConfiguration`** в реализации **`RepositoryRestConfigurer`**:

```java
@Configuration
public class RestConfig implements RepositoryRestConfigurer {
    @Override
    public void configureRepositoryRestConfiguration(
            RepositoryRestConfiguration config, CorsRegistry cors) {
        config.setBasePath("/api");
        config.exposeIdsFor(User.class);
    }
}
```

`setBasePath` задаёт общий префикс URI, `exposeIdsFor` включает поле идентификатора в представление указанной сущности. По умолчанию идентификатор доступен через URI ресурса, но обычно не выводится отдельным полем.

## Основные аннотации

- **`@RepositoryRestResource`** — настраивает ресурс репозитория: `path` задаёт путь, `collectionResourceRel` — имя отношения в ссылках, `exported` — возможность экспорта.
- **`@RestResource`** — настраивает путь, отношение или экспорт метода поиска и экспортируемых связей; `exported = false` скрывает соответствующий ресурс или метод.
- **`@Param`** — задаёт имя параметра поискового метода в URL.
- **`@Projection`** — задаёт именованное представление сущности с выбранными полями.
- **`@RepositoryRestController`** — регистрирует собственный контроллер в инфраструктуре Spring Data REST; методы могут возвращать `ResponseEntity` или использовать `@ResponseBody`.

```java
@RepositoryRestResource(path = "users", collectionResourceRel = "users")
public interface UserRepository extends JpaRepository<User, Long> {
    @RestResource(path = "by-name", rel = "by-name")
    List<User> findByName(@Param("name") String name);
}

@Projection(name = "short", types = User.class)
public interface UserShort {
    String getName();
}
```

Поиск доступен по `/api/users/search/by-name?name=Ann`, проекция — по `/api/users/1?projection=short`.
