## REST API

- `GET /atm/balance` — получение баланса.
- `POST /atm/deposits`, тело `amount=50000` — внесение 50 000 копеек.
- `POST /atm/withdrawals`, тело `amount=10000` — снятие 10 000 копеек.

POST-запросы используют `application/x-www-form-urlencoded`, успешные ответы — JSON. Денежные значения хранятся как целое число копеек. Счёт определяется по имени аутентифицированного пользователя из `getUserPrincipal()`; аутентификацию выполняет контейнер.

## Реализация сервлета

В модели счета хранятся в памяти, пользователь `demo` имеет начальный баланс 100 000 копеек. Физическое внесение и выдача банкнот заменены изменением баланса.

```java
import jakarta.servlet.annotation.WebServlet;
import jakarta.servlet.http.*;
import java.io.IOException;
import java.util.HashMap;
import java.util.Map;

@WebServlet("/atm/*")
public class AtmServlet extends HttpServlet {
    private final Map<String, Long> balances =
        new HashMap<>(Map.of("demo", 100_000L));

    @Override
    protected synchronized void doGet(HttpServletRequest req,
                                     HttpServletResponse resp)
            throws IOException {
        if (!"/balance".equals(req.getPathInfo())) {
            resp.sendError(404);
            return;
        }
        String account = account(req, resp);
        if (account == null) return;
        respond(resp, balances.get(account));
    }

    @Override
    protected synchronized void doPost(HttpServletRequest req,
                                      HttpServletResponse resp)
            throws IOException {
        boolean deposit = "/deposits".equals(req.getPathInfo());
        boolean withdrawal = "/withdrawals".equals(req.getPathInfo());
        if (!deposit && !withdrawal) {
            resp.sendError(404);
            return;
        }
        String account = account(req, resp);
        if (account == null) return;

        try {
            long amount = Long.parseLong(req.getParameter("amount"));
            if (amount <= 0) {
                resp.sendError(400, "Amount must be positive");
                return;
            }
            long balance = balances.get(account);
            if (withdrawal && amount > balance) {
                resp.sendError(409, "Insufficient funds");
                return;
            }
            long updated = deposit
                ? Math.addExact(balance, amount) : balance - amount;
            balances.put(account, updated);
            respond(resp, updated);
        } catch (NumberFormatException | ArithmeticException e) {
            resp.sendError(400, "Invalid amount");
        }
    }

    private String account(HttpServletRequest req,
                           HttpServletResponse resp) throws IOException {
        if (req.getUserPrincipal() == null) {
            resp.sendError(401);
            return null;
        }
        String id = req.getUserPrincipal().getName();
        if (!balances.containsKey(id)) {
            resp.sendError(404, "Account not found");
            return null;
        }
        return id;
    }

    private void respond(HttpServletResponse resp, long balance)
            throws IOException {
        resp.setContentType("application/json");
        resp.setCharacterEncoding("UTF-8");
        resp.getWriter().write("{\"balance\":" + balance + "}");
    }
}
```

Обработчики синхронизированы: проверка остатка и изменение баланса выполняются атомарно для одного экземпляра сервлета. В варианте с БД эти действия выполняются в транзакции с блокировкой счёта.

Успех возвращает `200 OK` и новый баланс. Ошибки: `400` — неверная сумма, `401` — нет аутентификации, `404` — неизвестный счёт или маршрут, `409` — недостаточно средств. Снятие оформляется через `POST`: операция изменяет баланс, но не удаляет счёт.
