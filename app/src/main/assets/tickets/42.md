## Условие

Реализовать управление банкоматом на сервлетах.

## REST API

- `GET /atm/balance?accountId=1` — баланс счёта.
- `POST /atm/deposits`, тело `accountId=1&amount=500` — внести 500 рублей.
- `POST /atm/withdrawals`, тело `accountId=1&amount=100` — снять 100 рублей.

## Сервис операций со счетами

`AtmService` хранит балансы нескольких счетов в рублях и выполняет операции атомарно.

```java
public class AtmService {
    private final Map<Long, Long> balances =
        new HashMap<>(Map.of(1L, 1000L, 2L, 2000L));

    public synchronized long getBalance(long accountId) {
        Long balance = balances.get(accountId);
        if (balance == null) {
            throw new NoSuchElementException("Account not found");
        }
        return balance;
    }

    public synchronized long deposit(long accountId, long amount) {
        checkAmount(amount);
        long updated = Math.addExact(getBalance(accountId), amount);
        balances.put(accountId, updated);
        return updated;
    }

    public synchronized long withdraw(long accountId, long amount) {
        checkAmount(amount);
        long balance = getBalance(accountId);
        if (amount > balance) {
            throw new IllegalStateException("Insufficient funds");
        }
        balances.put(accountId, balance - amount);
        return balance - amount;
    }

    private void checkAmount(long amount) {
        if (amount <= 0) {
            throw new IllegalArgumentException("Amount must be positive");
        }
    }
}
```

## Сервлет

Сервлет получает параметры запроса, вызывает сервис и возвращает баланс в JSON.

```java
@WebServlet("/atm/*")
public class AtmServlet extends HttpServlet {
    private final AtmService service = new AtmService();

    @Override
    protected void doGet(HttpServletRequest req,
                         HttpServletResponse resp) throws IOException {
        if (!"/balance".equals(req.getPathInfo())) {
            resp.sendError(404);
            return;
        }
        try {
            long id = Long.parseLong(req.getParameter("accountId"));
            respond(resp, service.getBalance(id));
        } catch (IllegalArgumentException e) {
            resp.sendError(400);
        } catch (NoSuchElementException e) {
            resp.sendError(404, e.getMessage());
        }
    }

    @Override
    protected void doPost(HttpServletRequest req,
                          HttpServletResponse resp) throws IOException {
        boolean deposit = "/deposits".equals(req.getPathInfo());
        boolean withdrawal = "/withdrawals".equals(req.getPathInfo());
        if (!deposit && !withdrawal) {
            resp.sendError(404);
            return;
        }
        try {
            long id = Long.parseLong(req.getParameter("accountId"));
            long amount = Long.parseLong(req.getParameter("amount"));
            long balance = deposit
                ? service.deposit(id, amount) : service.withdraw(id, amount);
            respond(resp, balance);
        } catch (IllegalArgumentException | ArithmeticException e) {
            resp.sendError(400);
        } catch (NoSuchElementException e) {
            resp.sendError(404, e.getMessage());
        } catch (IllegalStateException e) {
            resp.sendError(409, e.getMessage());
        }
    }

    private void respond(HttpServletResponse resp, long balance)
            throws IOException {
        resp.setContentType("application/json");
        resp.getWriter().write("{\"balance\":" + balance + "}");
    }
}
```
