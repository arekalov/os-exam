## Условие

Написать веб-сервис на JAX-RS, который управляет шлагбаумом.

## REST API

- `POST /api/barriers`, форма `address=Entrance` — зарегистрировать закрытый шлагбаум.
- `GET /api/barriers` — список шлагбаумов.
- `GET /api/barriers/{id}` — данные шлагбаума.
- `PUT /api/barriers/{id}/state`, тело `OPEN` или `CLOSED` — установить состояние.
- `DELETE /api/barriers/{id}` — удалить шлагбаум.

## Регистрация JAX-RS

```java
@ApplicationPath("/api")
public class BarrierApplication extends Application {
    @Override
    public Set<Class<?>> getClasses() {
        return Set.of(BarrierResource.class);
    }
}
```

## Ресурс шлагбаума

```java
@Path("/barriers")
@Produces("application/json")
public class BarrierResource {
    public enum State { OPEN, CLOSED }
    public record Barrier(long id, String address, State state) {}

    private static final Map<Long, Barrier> barriers = new ConcurrentHashMap<>();
    private static final AtomicLong ids = new AtomicLong();

    @POST
    @Consumes("application/x-www-form-urlencoded")
    public Response create(@FormParam("address") String address,
                           @Context UriInfo uri) {
        if (address == null || address.isBlank()) {
            throw new BadRequestException();
        }
        long id = ids.incrementAndGet();
        Barrier barrier = new Barrier(id, address, State.CLOSED);
        barriers.put(id, barrier);
        return Response.created(uri.getAbsolutePathBuilder()
                .path(Long.toString(id)).build()).entity(barrier).build();
    }

    @GET
    public Collection<Barrier> list() {
        return List.copyOf(barriers.values());
    }

    @GET
    @Path("/{id}")
    public Barrier get(@PathParam("id") long id) {
        Barrier barrier = barriers.get(id);
        if (barrier == null) throw new NotFoundException();
        return barrier;
    }

    @PUT
    @Path("/{id}/state")
    @Consumes("text/plain")
    public Barrier setState(@PathParam("id") long id, String value) {
        if (!"OPEN".equals(value) && !"CLOSED".equals(value)) {
            throw new BadRequestException();
        }
        State state = State.valueOf(value);
        Barrier updated = barriers.computeIfPresent(id,
            (key, old) -> new Barrier(key, old.address(), state));
        if (updated == null) throw new NotFoundException();
        return updated;
    }

    @DELETE
    @Path("/{id}")
    public void delete(@PathParam("id") long id) {
        if (barriers.remove(id) == null) throw new NotFoundException();
    }
}
```
