**Apache JMeter** — нагрузочное тестирование веб-приложений, API, БД. Имитирует виртуальных пользователей.

**Архитектура:** Test Plan → Thread Group → Samplers + Controllers + Timers + Assertions + Listeners. GUI — проектирование; Engine (non-GUI) — запуск нагрузки.

**Элементы:**
* **Thread Group** — виртуальные пользователи (threads, ramp-up, loop count)
* **Samplers** — HTTP Request, JDBC, FTP, SOAP
* **Logic Controllers** — Loop, If, While, Transaction, Random
* **Config Elements** — HTTP Defaults, Header Manager, CSV Data Set
* **Timers** — Constant, Gaussian Random, Uniform Random
* **Assertions** — Response, Duration, Size
* **Listeners** — View Results Tree (отладка), Aggregate Report (метрики)

**Порядок выполнения:**
1. Config Elements → 2. Pre-Processors → 3. Timers → 4. **Sampler** → 5. Post-Processors → 6. Assertions → 7. Listeners

Config и Timers действуют на элементы того же уровня и ниже.
