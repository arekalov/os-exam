## Условие

Необходимо разработать REST API для управления пользователями с использованием Spring Data REST. API должно предоставлять операции создания, получения, изменения и удаления пользователей, а также поиск по имени.

Spring Data REST позволяет автоматически создавать REST API на основе репозиториев Spring Data без необходимости вручную писать контроллеры `@RestController`.

### Сущность пользователя
Создадим сущность WebsiteUser, которая будет соответствовать таблице пользователей в базе данных.
```java
@Entity
@Data
public class WebsiteUser {

    @Id
    @GeneratedValue(strategy = GenerationType.AUTO)
    private Long id;

    private String name;
    private String email;
}
```

## Репозиторий
```java
@RepositoryRestResource( // указывает Spring Data REST публиковать репозиторий как REST API
    collectionResourceRel = "users", // задаёт имя отношения в ответах HAL
    path = "users" // задаёт путь к ресурсу
)
public interface UserRepository
        extends JpaRepository<WebsiteUser, Long> {

    List<WebsiteUser> findByName(@Param("name") String name); // метод поиска, запрос к БД формируется автоматически по названию метода
}
```

`JpaRepository` предоставляет CRUD-операции, пагинацию и сортировку.

## Главный класс приложения
Spring Boot автоматически обнаружит сущность и репозиторий, после чего Spring Data REST опубликует API.

```java
@SpringBootApplication
public class SpringDataRestApplication {

    public static void main(String[] args) {
        SpringApplication.run(
            SpringDataRestApplication.class, args
        );
    }
}
```

### REST API
После запуска приложения Spring Data REST автоматически создаст следующие endpoint:
* `GET	/users`	- Получить список пользователей
* `GET	/users/{id}`	- Получить пользователя по ID
* `POST	/users`	- Создать пользователя
* `PUT	/users/{id}`	- Полностью изменить пользователя
* `PATCH	/users/{id}`	- Частично изменить пользователя
* `DELETE	/users/{id}`	- Удалить пользователя
* `GET	/users/search/findByName?name=Ivan`	- Найти пользователей по имени

### Формат ответов
По умолчанию Spring Data REST использует HAL JSON — формат JSON с гиперссылками на связанные ресурсы.

Пример ответа:
```json
{
    "_embedded": {
        "users": [
            {
                "name": "Ivan",
                "email": "ivan@example.com",
                "_links": {
                    "self": {
                        "href": "http://localhost:8080/users/1"
                    }
                }
            }
        ]
    },
    "_links": {
        "self": {
            "href": "http://localhost:8080/users"
        }
    }
}
```
