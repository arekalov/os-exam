## Условие

Реализовать REST-сервис на JAX-RS для работы с корзиной покупок. Формат обмена данными — XML.

## Принятые правила работы и REST API

Корзина содержит товары, каждый из которых имеет идентификатор, название и описание.

Реализуем следующие операции:
Метод	URI	Назначение
* `GET	/api/cart`	- Получить содержимое корзины
* `POST	/api/cart/products`	- Добавить товар в корзину
* `DELETE	/api/cart/products/{id}`	- Удалить товар по ID
* `DELETE	/api/cart`	- Очистить корзину

Дополнительные правила:
- Идентификаторы товаров должны быть положительными и уникальными в рамках корзины.
- Нельзя добавить товар с ID, который уже есть в корзине.
- Корзина хранится в памяти приложения и является общей для всех запросов.

### Product.java
```java
@Data
@XmlRootElement(name = "product")
@XmlAccessorType(XmlAccessType.FIELD)
public class Product {
    @XmlElement(required = true)
    protected int id;

    @XmlElement(required = true)
    protected String name;

    @XmlElement(required = true)
    protected String description;
}
```

### Cart.java
```java
@Data
@XmlRootElement(name = "cart")
@XmlAccessorType(XmlAccessType.FIELD)
public class Cart {

    @XmlElement(name = "product")
    private List<Product> products = new ArrayList<>();
}
```

### Регистрация JAX-RS
```java
@ApplicationPath("/api")
public class ShopApplication extends Application {
    @Override
    public Set<Class<?>> getClasses() {
        return Set.of(CartResource.class);
    }
}
```

### Ресурс корзины
```java
@Path("/cart")
@Produces(MediaType.APPLICATION_XML)
public class CartResource {

    private static final Map<Integer, Product> CART =
        new LinkedHashMap<>();

    // Получить содержимое корзины
    @GET
    public Cart getCart() {
        Cart cart = new Cart();
        cart.setProducts(new ArrayList<>(CART.values()));
        return cart;
    }

    // Добавить товар в корзину
    @POST
    @Path("/products")
    @Consumes(MediaType.APPLICATION_XML)
    public Response addProduct(Product product) {
        if (product == null || product.getId() <= 0
                || product.getName() == null
                || product.getDescription() == null) {
            throw new BadRequestException("Invalid product data");
        }

        if (CART.containsKey(product.getId())) {
            throw new BadRequestException("Product already exists");
        }

        CART.put(product.getId(), product);

        return Response.status(Response.Status.CREATED)
            .entity(product)
            .build();
    }

    // Удалить товар по ID
    @DELETE
    @Path("/products/{id}")
    public Response removeProduct(@PathParam("id") int id) {
        if (CART.remove(id) == null) {
            throw new NotFoundException("Product not found");
        }

        return Response.noContent().build();
    }

    // Очистить корзину
    @DELETE
    public Response clearCart() {
        CART.clear();
        return Response.noContent().build();
    }
}
```
