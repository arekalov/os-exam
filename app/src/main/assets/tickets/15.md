### Понятие JAX-RS (Jakarta RESTful Web Services).
JAX-RS (Jakarta RESTful Web Services) — спецификация Java для создания RESTful веб-сервисов, определяет API, с помощью которого разработчики могут создавать REST API на Java, используя аннотации и классы для обработки HTTP-запросов. Позволяет:
- создавать RESTful endpoint;
- обрабатывать HTTP-методы (GET, POST, PUT, DELETE и другие);
- получать параметры запросов;
- преобразовывать Java-объекты в JSON, XML и другие форматы;
- формировать HTTP-ответы.

### Назначение спецификации.
Основная **цель** JAX-RS — стандартизировать разработку RESTful-сервисов на Java. До появления подобных спецификаций разработчики могли реализовывать обработку HTTP-запросов разными способами, что затрудняло переносимость приложений.

JAX-RS предоставляет единый подход:
- аннотации для определения URI и HTTP-методов;
- стандартные механизмы обработки запросов и ответов;
- поддержку различных форматов данных;
- возможность использования фильтров и перехватчиков;
- независимость от конкретной реализации.
Например, разработчик может использовать аннотацию @GET, не реализуя самостоятельно низкоуровневую обработку HTTP.

### Место JAX-RS в Java EE / Jakarta EE.
JAX-RS является частью платформы Java EE (Jakarta EE), благодаря чему работает на любом сервере приложений, и развивается в рамках Jakarta EE.
Внутри сервисов JAX-PS доступны API всех компонентов Java EE

Основные реализации:
* Jersey - Эталонная реализация JAX-RS
* RESTEasy - Реализация от Red Hat, используется в WildFly
* Apache CXF - Поддерживает JAX-RS и другие технологии веб-сервисо

### Основные компоненты и принципы работы.
Основой JAX-RS являются классы ресурсов (Resource Classes), которые обрабатывают HTTP-запросы. `Больше про аннотации в билете 16`

### Сходства и отличия от Spring Web MVC REST.
**Spring Web MVC REST** — часть Spring Framework, позволяющая создавать REST API с помощью контроллеров и аннотаций. Обе технологии решают похожие задачи, но основаны на разных подходах. **Главное отличие**: JAX-RS стандартизирует REST API для Java и может иметь разные реализации, а Spring Web MVC является частью конкретного фреймворка Spring.
| Критерий	| JAX-RS	| Spring Web MVC REST| 
|---|---|---|
| Тип	| Стандарт (спецификация)	| Фреймворк| 
| Основные аннотации	| @Path, @GET, @POST	| @RestController, @GetMapping, @PostMapping| 
| Обработка URI	| @Path| 	@RequestMapping| 
| Получение параметров	| @PathParam, @QueryParam	| @PathVariable, @RequestParam| 
| Работа с телом	| @Consumes, @Produces	| @RequestBody, @ResponseBody| 
| Реализация	| Jersey, RESTEasy	| Spring Framework|
