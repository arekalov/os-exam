## Зачем нужна

HTTP Basic Auth для веб-приложения — недостаточно. Политики безопасности задают **сквозные** правила доступа ко всем компонентам архитектуры (не только к URL), применимы на любом уровне.

Вторая задача — отображение набора прав на набор ролей конкретного пользователя.

## Роли и привилегии

**Роль** — высокоуровневое понятие, определяет *кем является* пользователь. Выдаётся администратором. Каждой роли соответствует набор привилегий.

**Привилегия** — низкоуровневое понятие, определяет *что пользователь может делать*. С помощью привилегий разграничивается доступ к ресурсам (чтение, изменение, удаление).

## Реализация на уровне бизнес-логики

В Spring — через Spring Security (`@PreAuthorize`, `@Secured`):

```java
@PreAuthorize("hasAuthority('WRITE_ARTICLES')")
public void createArticle(Article a) { ... }

@PreAuthorize("hasRole('ADMIN')")
public void deleteUser(long id) { ... }
```

- Spring — Spring Security
- Jakarta EE — JAAS
