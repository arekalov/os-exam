title: Выбор тестового покрытия с помощью анализа эквивалентности. Анализ граничных значений.
---

**Анализ эквивалентности** — входные данные делят на **классы эквивалентности**: значения, для которых программа ведёт себя одинаково. Из каждого класса берут одно тестовое значение.
* **Валидные классы** — допустимые значения
* **Невалидные классы** — недопустимые значения (ошибка)

**Шаги:** определить условия → разбить на классы → выбрать представителей → составить тест-кейсы.

**Пример** (возраст 18–65): валидный — 30; невалидные — 10, 70, «abc».

**Анализ граничных значений** — дефекты чаще на границах классов. Для диапазона [min, max] проверяют: min−1, min, min+1, max−1, max, max+1.

**Пример** (возраст 18–65): 17, 18, 19, 64, 65, 66.

Сначала — классы эквивалентности, затем — граничные значения.
