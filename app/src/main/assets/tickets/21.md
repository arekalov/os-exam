## Способы хранения учётных записей пользователей в Java
* В простейших случаях (например, демо) - в памяти (InMemoryUserDetailsManager), в properties-файлах (пары имя/пароль).
* В реляционной БД через JdbcUserDetailsManager (стандартные схемы Spring Security)
* В собственной реализации `UserDetailsService` (с Hibernate/JPA)
* В LDAP (Lightweight Directory Access Protocol) - для корпоративных систем
### Реализация на уровне бизнес-логики:
**UserDetailsService** - ключевой интерфейс Spring Security. Он имеет единственный метод `loadUserByUsername(String username)`, возвращающий объект `UserDetails` (содержит пароль, роли, флаги активности). Нужно реализовать этот интерфейс, подключаясь к своему хранилищу (например, через Hibernate к таблице users + authorities). Spring Security не заботится о том, где лежат данные, он только вызывает этот сервис при аутентификации. Хранение паролей — обязательно с хешированием (`BCrypt, Argon2`), никогда в открытом виде.
