## Сериализация и десериализация

**Сериализация** — преобразование Java-объекта в формат передачи, например JSON или XML. **Десериализация** — восстановление объекта из тела HTTP-запроса.

В Spring Web MVC эти операции выполняют **`HttpMessageConverter`**. Методы `canRead` и `canWrite` определяют поддерживаемые типы объектов и форматы, `read` и `write` выполняют преобразование.

Для JSON обычно используется **Jackson** с `ObjectMapper`; для XML — Jackson XML с `XmlMapper` либо JAXB. Нужные библиотеки и конвертеры должны быть подключены. Аннотации Jackson, например `@JsonProperty` и `@JsonIgnore`, позволяют управлять именами и составом полей.

## Выбор формата

- **`Content-Type`** запроса указывает формат переданного тела: например `application/json`.
- **`Accept`** сообщает допустимые форматы ответа.
- **`consumes`** ограничивает форматы запросов, принимаемые обработчиком.
- **`produces`** ограничивает форматы его ответов.

Конвертер выбирается по Java-типу и типу содержимого. Неподдерживаемый формат запроса приводит к `415 Unsupported Media Type`, невозможность сформировать приемлемый ответ — к `406 Not Acceptable`, некорректное тело — обычно к `400 Bad Request`.

## Передача объектов

```java
@RestController
public class UserController {
    @PostMapping(value = "/users/echo",
                 consumes = "application/json",
                 produces = "application/json")
    public UserDto echo(@RequestBody UserDto user) {
        return user;
    }
}

public record UserDto(String name, int age) {}
```

`@RequestBody` преобразует JSON в `UserDto`. Благодаря `@RestController` возвращаемый объект преобразуется обратно в JSON. Заголовок `Content-Type` ответа указывает фактически выбранный формат.
