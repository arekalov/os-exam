---

**Системные функции XPath** — встроенные функции для работы с узлами, числами, строками.

**Контекст и позиция:**
* `last()` — индекс последнего (`//tr[last()]`)
* `position()` — позиция узла (`//li[position()=1]`)
* `count(node-set)` — количество узлов

**Узлы:** `name()`, `local-name()`, `namespace-uri()`

**Boolean:** `boolean()`, `not()`, `true()`, `false()`, `lang('en')`

**Числа:** `number()`, `sum()`, `floor()`, `ceiling()`, `round()`

**Строки:** `string()`, `concat()`, `contains()`, `starts-with()`, `substring()`, `string-length()`, `normalize-space()`

**Прочие:** `id('element-id')` — по ID (нужен DTD)

В Selenium чаще всего: `last()`, `position()`, `count()`, `contains()`, `starts-with()`, `not()`.
