## Условие

Дан Spring Data репозиторий с одним методом. Необходимо превратить его в REST-сервис с помощью Spring Data REST и настроить публикацию API так, чтобы извне был доступен только этот метод.

## Подключение Spring Data REST

Добавляем зависимость в pom.xml:
```xml
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-data-rest</artifactId>
</dependency>
```

Добавляем в application.properties: `spring.data.rest.detection-strategy=visibility`. Стратегия `visibility` означает, что Spring Data REST обнаруживает публичные репозитории.

## Создание Spring Data Repository
```java
@RepositoryRestResource(
    collectionResourceRel = "car", // имя отношения для коллекции в гипермедиа-ответе
    path = "cars"  // базовый URI репозитория
)
public interface CarRepository extends Repository<Car, Long> {
    @RestResource(path = "by-model", rel = "by-model") // задаёт путь для REST endpoint
    List<Car> findByModel(@Param("model") String model);
}
```

### Получившийся REST API
Единственный опубликованный метод:
```
GET /cars/search/by-model?model=BMW
Accept: application/hal+json
```
Пример ответа:
```json
{
    "_embedded": {
        "car": [
            {
                "id": 1,
                "model": "BMW",
                "color": "Black"
            },
            {
                "id": 2,
                "model": "BMW",
                "color": "White"
            }
        ]
    }
}
```
