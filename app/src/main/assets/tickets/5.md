## Spring Boot vs Spring

Spring Boot — расширение Spring, устраняющее необходимость ручной настройки.

- **Spring**: ручная конфигурация (XML / Java Config), отдельный сервер, ручное управление зависимостями
- **Spring Boot**: автоконфигурация по classpath, встроенный Tomcat/Jetty, starter-зависимости

## Ключевые возможности

- **Автоконфигурация** — Spring Boot анализирует classpath и создаёт нужные бины автоматически. Есть `H2` в classpath → DataSource настраивается сам. Отключить: `@SpringBootApplication(exclude = DataSourceAutoConfiguration.class)`
- **Starter-зависимости** — `spring-boot-starter-web`, `spring-boot-starter-data-jpa` и т.д. Подтягивают все нужные зависимости одной строкой
- **Встроенный сервер** — Tomcat встроен, деплоить war не нужно, запуск через `main()`

## Профили (Spring Boot Profiles)

Профили позволяют иметь разные конфигурации для разных окружений (dev, prod, test).

**Файлы конфигурации:**
- `application.properties` — общие настройки
- `application-dev.properties` — настройки для профиля dev
- `application-prod.properties` — настройки для профиля prod

**Активация профиля:**
- В `application.properties`: `spring.profiles.active=dev`
- Через переменную окружения: `SPRING_PROFILES_ACTIVE=prod`
- Программно: `SpringApplication.setAdditionalProfiles("dev")`

**Бины под конкретный профиль:**
```java
@Profile("dev")
@Bean
public DataSource devDataSource() { ... }

@Profile("prod")
@Bean
public DataSource prodDataSource() { ... }
```
