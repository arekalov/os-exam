**Тестирование алгоритмов в JUnit 5** — проверка корректности на наборе входов: результат, граничные случаи, исключения.

**Что проверять:**
* Корректность результата для типичного ввода
* **Граничные случаи:** пустой ввод, один элемент, min/max, уже отсортированное
* **Особые случаи:** дубликаты, null, отрицательные числа
* **Исключения:** `assertThrows(...)`
* **Инварианты:** свойства после выполнения (сумма элементов при сортировке)

**Пример (сортировка):**

```java
@Test
void emptyArray() {
    int[] arr = {};
    sorter.sort(arr);
    assertArrayEquals(new int[]{}, arr);
}

@Test
void reverseSorted() {
    int[] arr = {5, 4, 3, 2, 1};
    sorter.sort(arr);
    assertArrayEquals(new int[]{1, 2, 3, 4, 5}, arr);
}

@Test
void nullInput() {
    assertThrows(IllegalArgumentException.class, () -> sorter.sort(null));
}
```

**Параметризация:**

```java
@ParameterizedTest
@MethodSource("sortCases")
void testSort(int[] input, int[] expected) {
    sorter.sort(input);
    assertArrayEquals(expected, input);
}
```

Тесты должны быть **детерминированными, быстрыми, независимыми** (`@BeforeEach` для инициализации).
