## Назначение хранилищ

**KeyStore** — хранилище собственных приватных ключей и соответствующих цепочек сертификатов. Используется для аутентификации приложения перед другой стороной TLS-соединения.

**TrustStore** — хранилище доверенных сертификатов, обычно корневых CA. Используется для проверки сертификатов удалённой стороны. Может содержать конкретные самоподписанные сертификаты, которым приложение явно доверяет.

Оба хранилища используют API **`java.security.KeyStore`** и одинаковые форматы файлов, но различаются назначением и составом записей. Записи идентифицируются именем **alias**. Один файл может совмещать обе роли.

## Использование при TLS-соединении

- **Односторонняя аутентификация:** сервер использует приватный ключ и сертификат из KeyStore, клиент проверяет сертификат сервера на основе TrustStore.
- **Взаимная аутентификация (mTLS):** каждая сторона использует KeyStore для подтверждения своей идентичности и TrustStore для проверки другой стороны.
- **KeyManager** выбирает ключ и цепочку сертификатов; **TrustManager** проверяет полученную цепочку.

При handshake передаются сертификаты и доказательства владения ключами. Приватные ключи остаются в соответствующих хранилищах.

## Форматы хранилищ

- **JKS (Java KeyStore)** — исторический формат Java для приватных ключей и сертификатов.
- **PKCS12** — стандартный переносимый формат, обычно с расширением `.p12` или `.pfx`; используется по умолчанию начиная с Java 9.

Хранилище защищается паролем. Для создания и управления записями применяется утилита **keytool**.
