## Условие

Реализовать казино слот-машину на Jax-RS.

## Принятые правила игры и REST API

`POST /api/slots/spins` выполняет одно вращение трёх барабанов. Ставка передаётся параметром формы `bet`, ответ возвращается в JSON. Используются условные игровые единицы; ставка — целое число от 1 до 10 000.

Каждый барабан независимо выдаёт символ от 0 до 5. Три одинаковых символа дают выплату `10 × bet`, ровно два одинаковых — `2 × bet`, остальные комбинации — 0. Чистый результат равен выплате минус ставка.

## Регистрация JAX-RS

```java
@ApplicationPath("/api")
public class CasinoApplication extends Application {
    @Override
    public Set<Class<?>> getClasses() {
        return Set.of(SlotResource.class);
    }
}
```

## Ресурс слот-машины

```java
@Path("/slots")
@Produces(MediaType.APPLICATION_JSON)
public class SlotResource {
    private static final SecureRandom RANDOM = new SecureRandom();

    @POST
    @Path("/spins")
    @Consumes(MediaType.APPLICATION_FORM_URLENCODED)
    public Map<String, Object> spin(@FormParam("bet") long bet) {
        if (bet <= 0 || bet > 10_000) {
            throw new BadRequestException("bet must be between 1 and 10000");
        }

        int a = RANDOM.nextInt(6);
        int b = RANDOM.nextInt(6);
        int c = RANDOM.nextInt(6);
        int multiplier = a == b && b == c ? 10
            : a == b || a == c || b == c ? 2 : 0;
        long payout = bet * multiplier;

        return Map.of(
            "reels", List.of(a, b, c),
            "bet", bet,
            "payout", payout,
            "net", payout - bet
        );
    }
}
```

Классы размещаются в отдельных файлах. Приложение разворачивается в среде JAX-RS с JSON-провайдером, например Jackson. Результат вращения вычисляется сервером; состояние кошелька в этой модели не хранится.

Пример запроса: `POST /api/slots/spins`, `Content-Type: application/x-www-form-urlencoded`, тело `bet=10`.

Пример ответа `200 OK`:

```json
{"reels":[3,3,3],"bet":10,"payout":100,"net":90}
```

Некорректная ставка возвращает `400 Bad Request`. Вращение выполняется через `POST`, поскольку каждый вызов создаёт новый результат игры.
