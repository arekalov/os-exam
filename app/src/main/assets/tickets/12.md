## Что даёт Spring Boot

Spring Boot — надстройка над Spring Framework, убирающая шаблонный код конфигурации.

## Автоконфигурация

`@EnableAutoConfiguration` анализирует classpath и регистрирует бины автоматически. Если в classpath есть `spring-data-jpa` + DataSource → автоматически создаётся `JpaTransactionManager`, `EntityManagerFactory` и т.д.

Конфигурацию можно переопределить в `application.properties` / `application.yml`.

## Starter-зависимости

Вместо явного указания десятков зависимостей — один стартер:

- `spring-boot-starter-web` — Spring MVC + встроенный Tomcat
- `spring-boot-starter-data-jpa` — Spring Data JPA + Hibernate
- `spring-boot-starter-security` — Spring Security

## Встроенный сервер

Spring Boot запускает встроенный Tomcat (или Jetty/Undertow). Приложение упаковывается в исполняемый JAR — не нужен внешний сервер приложений.

## @SpringBootApplication

Три аннотации в одной:
- `@Configuration` — класс конфигурации
- `@ComponentScan` — сканирование компонентов
- `@EnableAutoConfiguration` — автоконфигурация

## Ключевые отличия

| | Spring | Spring Boot |
|---|---|---|
| Конфигурация | XML или Java Config | Auto-configuration |
| Сервер | Внешний | Встроенный |
| Зависимости | Вручную | Starters |
| Запуск | WAR → сервер | JAR → `java -jar` |
