## Основные аннотации

- `@RestController` — контроллер, возвращающий JSON (`@Controller` + `@ResponseBody`)
- `@GetMapping` / `@PostMapping` — HTTP методы
- `@RequestParam` — параметр запроса (`?from=1`)
- `@PathVariable` — часть URL (`/item/{id}`)
- `@RequestBody` — тело запроса (JSON → объект)

## Перевод денег с проверкой лимита

```java
@PostMapping("/transfer")
@Transactional
public void transfer(@RequestParam long from, @RequestParam long to, @RequestParam long amount) {
    User sender = userRepo.getById(from);
    User receiver = userRepo.getById(to);
    if (sender.getMonthlyLimit() < sender.getMonthlySpent() + amount)
        throw new TransferLimitExceededException();
    if (sender.getBalance() < amount)
        throw new NotEnoughMoneyException();
    sender.setBalance(sender.getBalance() - amount);
    receiver.setBalance(receiver.getBalance() + amount);
}
```

## Оплата автобуса (идемпотентность)

```java
@PostMapping("/pay")
public void pay(@RequestParam long passengerId) {
    User p = passengerRepo.getById(passengerId);
    if (p.getBalance() < PRICE) throw new NotEnoughMoneyException();
    if (p.getLastPaidDay().equals(LocalDate.now())) return; // уже оплачено
    p.setBalance(p.getBalance() - PRICE);
    p.setLastPaidDay(LocalDate.now());
}
```
