## jBPM
**jBPM** — движок на Java от компании JBoss для реализации потоков рабочих процессов (workflow)
Ядро jBPM легкое, написано на Java, позволяет запускать бизнес процессы используя нотацию
BPMN 2.0, его можно запустить в любой Java среде, встроить в приложение или
запустить как сервис.

В дополнение к основному движку предлагается множество функций и инструментов для
поддержки бизнес-процессов на протяжении всего жизненного цикла:
* Поддержка Eclipse и веб редактора для графического создания бизнес процессов
(drag & drop).
* Поддержка взаимозаменяемости и транзакции на основе JPA / JTA.
* Служба задач для персона основана на WS-HumanTask.
* Консоль управления, поддерживающая управление экземпляром процесса, списки
задач и управление формой задачи, а также отчетность.
* Дополнительный репозиторий процессов для развертывания вашего процесса (и
других связанных с ним знаний).
* Ведение журналирования (для запросов / мониторинга / анализа)
* Интеграция с Seam, Spring, OSGi, etc.

## Основные компоненты Camunda

* Modeler — приложение для создания моделей BPMN процессов, нужных для других частей системы.
* Task list — веб-приложение, в котором исполнители выполняют задачи, поставленные на них бизнес-процессом.
* BPMN Engine — непосредственно движок, отвечающий за интерпретацию BPMN в объекты JAVA, сохранение объектов в базе и реализацию других вещей (типа листенеров активностей), которые крутятся вокруг процессов.
* DMN Engine — аналог BPMN Engine для DMN.
* Cockpit - веб приложение для просмотра состояния процессов.
* Admin - веб приложение для управления пользователями и правами доступа
* Optimize - (платное) приложение для анализа и оптимизации бизнес-процессов
