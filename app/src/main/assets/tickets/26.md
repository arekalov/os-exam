**JUnit 5** — модуль `junit-jupiter-params` для параметризованных и динамических тестов.

## Параметризованные тесты

`@ParameterizedTest` — один метод запускается с разными наборами данных.

**Источники параметров:**
* `@ValueSource(ints = {1, 2, 3})` / `strings`, `doubles` — простые значения
* `@NullSource` + `@ValueSource` через `@NullAndEmptySource`
* `@EnumSource(MyEnum.class)` — значения enum
* `@CsvSource({"2, 3, 5", "0, 0, 0"})` — CSV в аннотации
* `@CsvFileSource(resources = "/data.csv")` — из файла
* `@MethodSource("methodName")` — из статического метода, возвращает `Stream<Arguments>`

```java
@ParameterizedTest
@CsvSource({"18, true", "30, true", "17, false", "66, false"})
void testAge(int age, boolean expected) {
    assertEquals(expected, validator.isValid(age));
}

static Stream<Arguments> boundaryValues() {
    return Stream.of(
        Arguments.of(17, false),
        Arguments.of(18, true),
        Arguments.of(65, true),
        Arguments.of(66, false)
    );
}
```

## Другие возможности JUnit 5

* `@RepeatedTest(n)` — повторить тест n раз
* `@TestFactory` — динамическое создание тестов (`DynamicTest`)
* `@Nested` — вложенные классы для группировки
* `@Tag("smoke")` — метки для выборочного запуска
* `Assumptions.assumeTrue(cond)` — пропуск теста (не fail), если условие ложно
* `@ExtendWith(MockitoExtension.class)` — интеграция с Mockito

Параметризация удобна для эквивалентности и граничных значений.
