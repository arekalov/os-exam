title: Анализ эквивалентности с использованием JUnit.
---

**Суть:** классы эквивалентности реализуются как JUnit 5-тесты или `@ParameterizedTest`.

**Алгоритм:**
1. Определить входные условия
2. Выделить валидные и невалидные классы
3. Выбрать представителя из каждого класса
4. Написать `@Test` на класс или `@ParameterizedTest` с `@CsvSource` / `@MethodSource`

**Пример** (возраст 18–65) — отдельные тесты:

```java
@Test
void validAge() { assertTrue(validator.isValid(30)); }

@Test
void tooYoung() { assertFalse(validator.isValid(10)); }

@Test
void tooOld() { assertFalse(validator.isValid(70)); }
```

**Параметризованный вариант** (классы + граничные значения):

```java
@ParameterizedTest
@CsvSource({"18, true", "30, true", "65, true", "17, false", "66, false"})
void testAge(int age, boolean expected) {
    assertEquals(expected, validator.isValid(age));
}
```

При нескольких полях — `@MethodSource` с `Stream<Arguments>` или таблица решений. К классам эквивалентности добавляют граничные: min, min+1, max−1, max.
