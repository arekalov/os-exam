## Условие

Необходимо настроить Spring Data REST так, чтобы скрыть стандартные CRUD-методы репозитория и открыть доступ только к выбранным пользовательским методам.

### Настройка обнаружения репозиториев
В application.properties: `spring.data.rest.detection-strategy=annotation`
Стратегия annotation - Spring Data REST будет публиковать только репозитории, явно помеченные аннотацией @RepositoryRestResource.

### Реализация репозитория
```java
@RepositoryRestResource
public interface UserRepository extends Repository<User, Long> {

    @RestResource(exported = false)
    User save(User user);

    @RestResource(exported = false) // запрещает публикацию метода в REST API
    Optional<User> findById(Long id);

    @RestResource // разрешает публикацию метода
    Optional<User> findByUsername(String username);

    @RestResource
    void deleteByCityName(String cityName);
}
```

###  Доступные REST endpoint
При стандартной настройке Spring Data REST и отсутствии дополнительных параметров пути методы поиска публикуются в разделе /search.
* `findByUsername()`	- `GET	/users/search/findByUsername?username=Ivan`
* `deleteByCityName()`	- `DELETE	/users/search/deleteByCityName?cityName=Moscow`
