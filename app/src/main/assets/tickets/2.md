## CDI и IoC

**IoC (Inversion of Control)** — принцип, при котором управление созданием и жизненным циклом объектов передаётся контейнеру, а не программисту.

**DI (Dependency Injection)** — основной способ реализации IoC. Зависимости передаются объекту извне, а не создаются им самим.

**CDI (Contexts and Dependency Injection)** — стандарт Java EE/Jakarta EE для реализации DI и управления контекстами.

В Spring реализуется через:
- `@Component`, `@Service`, `@Repository` — объявление бинов
- `@Autowired` — внедрение зависимостей

## Управление транзакциями

Транзакция — группа операций, выполняемых как единое целое.

- На уровне бизнес-логики транзакции управляются через менеджеры транзакций
- В Spring — через `@Transactional` (декларативно) или `TransactionTemplate` (программно)
- Для распределённых транзакций используется JTA (Java Transaction API)

## Безопасность

- Разграничение доступа реализуется через роли и привилегии
- **Роль** — высокоуровневое понятие, определяет кем является пользователь
- **Привилегия** — низкоуровневое понятие, определяет что пользователь может делать
- В Spring реализуется через Spring Security
- Стандарт Java EE — JAAS

## Распределённая обработка данных

- Бизнес-логика может быть размазана по нескольким узлам
- Узлы могут быть однородными или неоднородными
- Требует синхронизации — распределённые транзакции, очереди сообщений
- Обычно многопоточная — несколько запросов обрабатываются параллельно
