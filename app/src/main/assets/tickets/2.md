## Разделяемая память

**Разделяемая память** (shared memory) — область памяти (по умолчанию 128MB), общая для всех процессов PostgreSQL. Она выделяется при старте кластера (`pg_ctl start`) и содержит критические структуры, которые должны быть доступны всем серверным процессам для координированной работы. Служит для минимизации числа операций обмена с дискам, храня копии блоков данных (страниц), считанных из файлов данных. В отличие от других СУБД, PostgreSQL активно использует разделяемую память даже для небольших временных структур, что делает её настройку (размер `shared_buffers`, `max_connections`) критически важной.

Основные компоненты разделяемой памяти:
* **Буферный кэш** (shared buffers) — кэш страниц таблиц и индексов, настраивается параметром shared_buffers.
* **Журнал предзаписи** (WAL) — буферы для WAL-записей, управляются параметром wal_buffers.
* **Таблицы блокировок** — информация о всех удерживаемых и ожидаемых блокировках (LWLocks, спин-локи, расширенные блокировки объектов).
* **Слоты для процессов** — для каждого бэкенда резервируется небольшой слот в разделяемой памяти для отслеживания его состояние.
* **Глобальные карты видимости** — для отслеживания страниц, не требующих очистки (all-visible).
