## JMS
**JMS** (Java Message Service) — стандарт Java API для создания, отправки, получения и чтения сообщений между компонентами распределенных приложений. Он обеспечивает асинхронную, слабосвязанную и надежную коммуникацию через очереди (point-to-point) или топики (publish/subscribe). Любой компонент, использующий JMS, прежде всего должен создать соединение с JMS провайдером. Для этого, нужно создать необходимые **ресурсы**. **Группа ресурсов JMS** – модуль адаптера ресурсов, обеспечивающий связывание фабрик соединений, очередей и т. п., которые можно получить с помощью JNDI lookup.


## Сообщения JMS

JMS состоит из определенных сообщений и клиентов обменивающимися ими.
Сообщение состоит из трех частей: заголовок, свойств и тело.
* **Заголовок** – содержит информацию, которая используется для маршрутизации и идентификации сообщений (обязательный). Заголовок хранит мета информацию сообщения, заполняемую автоматически (JMSCorrelationID, JMSDeliveryMode, JMSDestination).
* **Свойство** – содержит информацию, которую можно использовать для фильтрации сообщений (время, дата и т. п.). Поле свойств схоже с заголовком, но оно заполняется программно, и позже получатель сможет прочитать эту информацию.
* **Тело** – содержит информацию о типе сообщения (определяется при создании сообщения) и полезную нагрузку.
