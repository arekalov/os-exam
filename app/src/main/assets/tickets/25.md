**JUnit 5** — актуальная версия фреймворка. Класс **`org.junit.jupiter.api.Assertions`** — статические методы проверки ожидаемого результата. При несовпадении — `AssertionError`, тест failed.

У большинства методов есть перегрузка `(String message, ...)` — сообщение при провале.

## Проверка условий

* `assertTrue(boolean condition)` / `assertTrue(Supplier<String>, condition)`
* `assertFalse(boolean condition)` / `assertFalse(Supplier<String>, condition)`

## Сравнение значений

* `assertEquals(expected, actual)` — Object, примитивы (int, long, char, byte, short)
* `assertEquals(expected, actual, delta)` — double/float с погрешностью
* `assertNotEquals(unexpected, actual)` — значения не равны
* `assertArrayEquals(expected, actual)` — массивы (int[], Object[] и др.)

## Проверка ссылок

* `assertSame(expected, actual)` — одна ссылка (`==`)
* `assertNotSame(expected, actual)` — разные ссылки

## Проверка null

* `assertNull(object)` / `assertNotNull(object)`

## Исключения и время

* `assertThrows(Class<T>, Executable)` — ожидаемое исключение, возвращает исключение
* `assertDoesNotThrow(Executable)` — исключение не выбрасывается
* `assertTimeout(Duration, Executable)` — выполнение укладывается во время
* `assertTimeoutPreemptively(Duration, Executable)` — прерывает поток при превышении

## Групповые и составные проверки

* `assertAll(Executable...)` — все проверки выполняются, даже если одна упала
* `assertIterableEquals(expected, actual)` — сравнение Iterable
* `assertLinesMatch(expected, actual)` — сравнение строк построчно

## Принудительный провал

* `fail()` / `fail(String message)` / `fail(String message, Throwable cause)`

**JUnit 5** (`org.junit.jupiter.api`) — аннотации управляют жизненным циклом и запуском тестов.

## Основные аннотации

* `@Test` — тестовый метод
* `@BeforeEach` — перед **каждым** тестом (инициализация)
* `@AfterEach` — после **каждого** теста (очистка)
* `@BeforeAll` — **один раз** перед всеми тестами класса (**static**)
* `@AfterAll` — **один раз** после всех тестов класса (**static**)
* `@Disabled("причина")` — пропустить тест или класс
* `@DisplayName("описание")` — человекочитаемое имя теста

## Порядок выполнения

```
@BeforeAll → (@BeforeEach → @Test → @AfterEach) × N → @AfterAll
```

`@BeforeEach/@AfterEach` — изоляция тестов (новый объект перед каждым).
`@BeforeAll/@AfterAll` — дорогая однократная настройка (подключение к БД, запуск сервера).

## Пример

```java
class CalculatorTest {
    Calculator calc;

    @BeforeEach
    void setUp() { calc = new Calculator(); }

    @Test
    @DisplayName("Сложение двух чисел")
    void testAdd() {
        assertEquals(5, calc.add(2, 3));
    }

    @AfterEach
    void tearDown() { calc = null; }
}
```

## Проверка исключений и таймаута

* `assertThrows(IllegalArgumentException.class, () -> calc.div(1, 0))`
* `assertTimeout(Duration.ofMillis(100), () -> calc.heavyOperation())`
