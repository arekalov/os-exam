## JTA (Java Transaction API)

Стандартный API для управления распределёнными транзакциями в Jakarta EE.
- Реализует стандарт X/Open XA
- Контейнер содержит менеджер транзакций, управляющий ресурсами
- Требует XA-совместимых JDBC-драйверов и DataSource

## Два режима управления в EJB

**BMT (Bean-Managed) — программный:**

Программист сам управляет через `UserTransaction`:

```java
utx.begin();
try { ...; utx.commit(); }
catch (Exception e) { utx.rollback(); }
```

**CMT (Container-Managed) — декларативный:**

Контейнер управляет через `@TransactionAttribute(TransactionAttributeType.REQUIRED)`.

## Spring JTA

Spring Boot поддерживает JTA-транзакции двумя способами:

- **Сервер приложений Jakarta EE** (WildFly, GlassFish) — JTA встроен
- **Встроенный TM** — Atomikos (`spring-boot-starter-jta-atomikos`) или Bitronix

В обоих случаях `@Transactional` работает одинаково — Spring сам выбирает нужный `JtaTransactionManager`.
