## Назначение

**keytool** — утилита JDK для ключей, сертификатов и хранилищ JKS/PKCS12. `-keystore` задаёт файл, `-alias` — имя записи, `-storetype` — формат. Если пароль не указан, утилита запросит его.

## Основные команды

Примеры команд для сертификата локального сервера `localhost`:

```bash
# Пара ключей и самоподписанный сертификат; создаст хранилище
keytool -genkeypair -alias server -keyalg RSA -keysize 2048 \
  -storetype PKCS12 -keystore server.p12 -validity 365 \
  -dname "CN=localhost" -ext "SAN=dns:localhost,ip:127.0.0.1"

# CSR: запрос CA на сертификат для уже существующего ключа
keytool -certreq -alias server -keystore server.p12 \
  -file server.csr -ext "SAN=dns:localhost,ip:127.0.0.1"

# Экспорт публичного сертификата в PEM, без приватного ключа
keytool -exportcert -rfc -alias server \
  -keystore server.p12 -file server.crt

# Доверие этому сертификату на клиенте, например для локального теста
keytool -importcert -alias server -file server.crt \
  -storetype PKCS12 -keystore client-trust.p12

# Содержимое хранилища и отдельный сертификат
keytool -list -v -keystore server.p12
keytool -list -v -alias server -keystore server.p12
keytool -printcert -v -file server.crt

# Новый пароль хранилища будет запрошен интерактивно
keytool -storepasswd -keystore server.p12

# Удалить запись из клиентского хранилища доверия
keytool -delete -alias server -keystore client-trust.p12
```

## Получение сертификата от CA

Запрос `server.csr` передаётся центру сертификации. После проверки сертификата CA он добавляется в хранилище, а ответ CA импортируется **под alias существующего приватного ключа**:

```bash
keytool -importcert -alias root-ca -file root-ca.crt \
  -keystore server.p12
keytool -importcert -alias server -file server-chain.p7b \
  -keystore server.p12
```

Второй импорт заменяет самоподписанную цепочку выданной CA, сохраняя приватный ключ. В ответе должна быть доступна нужная цепочка промежуточных сертификатов.
