title: Система Selenium. Selenium RC, WebDriver, Grid.
---

**Selenium RC (1.x)** — устаревший. Тест → RC Server → JavaScript в браузере → DOM. Медленный, deprecated.

**Selenium WebDriver (2+)** — современный стандарт. Тест → Browser Driver → нативный API браузера. Быстрее, стабильнее. Стандарт W3C WebDriver. Драйверы: ChromeDriver, GeckoDriver, EdgeDriver.

**Selenium Grid** — распределённый запуск:
* **Hub/Master** — маршрутизация тестов
* **Node/Slave** — машины с браузерами, генерируют нагрузку
* Параллельно на разных ОС/браузерах
* Подключение: `RemoteWebDriver(new URL("http://hub:4444"), caps)`

| | RC | WebDriver | Grid |
|---|-----|-----------|------|
| Управление | Через JS | Нативный API | WebDriver на Slave |
| Статус | Deprecated | Актуальный | Актуальный |
| Масштаб | — | Локально | Много машин |

Современный стек: WebDriver + JUnit/TestNG + Grid (при необходимости) + Page Object.
