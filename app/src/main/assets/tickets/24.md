## Экспорт репозиториев

**Экспорт** — публикация HTTP-ресурсов на основе репозитория Spring Data. Выбор репозиториев определяет **`RepositoryDetectionStrategy`**.

- **`DEFAULT`** — экспортирует публичные репозитории и явно помеченные `@RepositoryRestResource`, учитывая `exported = false`.
- **`ALL`** — выбирает все репозитории независимо от видимости интерфейса и аннотации репозитория.
- **`ANNOTATED`** — выбирает только репозитории с `@RepositoryRestResource`, если `exported` не равен `false`.
- **`VISIBILITY`** — выбирает только публичные интерфейсы репозиториев независимо от аннотации репозитория.

Стратегия обнаружения выбирает репозитории; экспорт отдельных методов настраивается отдельно.

## Настройка стратегии

```properties
spring.data.rest.detection-strategy=annotated
```

При такой настройке публикуются только явно отмеченные репозитории:

```java
@RepositoryRestResource
public interface UserRepository extends CrudRepository<User, Long> {}
```

Программный вариант в `RepositoryRestConfigurer`:

```java
config.setRepositoryDetectionStrategy(
    RepositoryDetectionStrategies.ANNOTATED);
```

## Ограничение доступа к ресурсам

`@RepositoryRestResource(exported = false)` скрывает весь репозиторий при стратегиях `DEFAULT` и `ANNOTATED`.

`@RestResource(exported = false)` исключает отдельный метод из HTTP API, сохраняя возможность его вызова из Java-кода:

```java
@RepositoryRestResource
public interface UserRepository extends CrudRepository<User, Long> {
    @RestResource(exported = false)
    List<User> findByEmail(@Param("email") String email);

    @Override
    @RestResource(exported = false)
    void deleteById(Long id);

    @Override
    @RestResource(exported = false)
    void delete(User user);
}
```

В примере скрыт поиск по email и отключено удаление элемента через HTTP. `setExposeRepositoryMethodsByDefault(false)` переводит экспорт методов в режим явного разрешения через `@RestResource`. Отдельные HTTP-методы также ограничиваются через `ExposureConfiguration`.
