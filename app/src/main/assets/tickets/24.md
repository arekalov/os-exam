## Что такое Spring Security

Фреймворк аутентификации, авторизации и ролевого разграничения в составе Spring. Обеспечивает сквозное разграничение доступа на всех уровнях. Реализует паттерн цепочки фильтров (Filter Chain). Есть интеграция с JAAS.

## Поток аутентификации

1. Запрос проходит по цепочке фильтров, нужный фильтр его перехватывает
2. Фильтр создаёт объект `Authentication` и передаёт в `AuthenticationManager`
3. `ProviderManager` (дефолтная реализация) делегирует набору `AuthenticationProvider`
4. `AuthenticationProvider` проверяет credentials через `UserDetailsService`
5. При успехе — `Authentication` сохраняется в `SecurityContext`
6. При неудаче — бросается `AuthenticationException`

## Ключевые объекты

- `SecurityContextHolder` — хранит текущий контекст безопасности (ThreadLocal)
- `SecurityContext` — содержит объект `Authentication`
- `Authentication` — представляет пользователя (Principal)
- `GrantedAuthority` — разрешение/роль пользователя (`ROLE_ADMIN`, `ROLE_USER`)
- `UserDetails` — данные пользователя: логин, пароль, роли, флаги блокировки
- `UserDetailsService` — загружает `UserDetails` из хранилища (БД, memory, properties)

## Аннотации

- `@Secured("ROLE_ADMIN")` — доступ только для роли
- `@PreAuthorize("hasAuthority('WRITE')")` — проверка SpEL до вызова метода
- `@PostAuthorize("returnObject.owner == authentication.name")` — проверка после

## Конфигурация

```java
@Bean
public SecurityFilterChain filterChain(HttpSecurity http) throws Exception {
    http.authorizeHttpRequests(auth -> auth
        .requestMatchers("/admin/**").hasRole("ADMIN")
        .anyRequest().authenticated()
    );
    return http.build();
}
```
