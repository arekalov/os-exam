## Условие

Restful-сервис на базе сервлета, реализующий механизм управления номеронабирателем телефонного аппарата. Номеронабиратель должен поддерживать функции локальных, междугородних и международных звонков, а также автодозвон.

## REST API

- `POST /phone/call` — начать звонок; параметры формы: `type`, `number`, `attempts`.
- `GET /phone/call` — состояние: `IDLE`, `DIALING`, `CONNECTED`, `FAILED`.
- `DELETE /phone/call` — завершить звонок или отменить автодозвон.

Типы звонков: `LOCAL` — локальный номер из 5–7 цифр; `NATIONAL` — 10 цифр, включая код города; `INTERNATIONAL` — `+` и 8–15 цифр с кодом страны. `attempts=1` означает обычный звонок, значение от 2 до 10 — автодозвон с интервалом 5 секунд между неудачными попытками.

## Интерфейс сервиса

`start` запускает звонок и автодозвон в фоне. Некорректные параметры приводят к `IllegalArgumentException`, занятый аппарат — к `IllegalStateException`.

```java
public interface PhoneService {
    void start(String type, String number, int attempts);
    String state();
    void stop();
    void close();
}
```

## Сервлет

Реализация сервиса передаётся через атрибут `phoneService` контекста приложения.

```java
@WebServlet("/phone/call")
public class PhoneServlet extends HttpServlet {
    private PhoneService phone;

    @Override
    public void init() {
        phone = (PhoneService) getServletContext().getAttribute("phoneService");
    }

    @Override
    protected void doPost(HttpServletRequest req,
                          HttpServletResponse resp) throws IOException {
        try {
            String type = req.getParameter("type");
            if (type == null) throw new IllegalArgumentException();
            String attempts = req.getParameter("attempts");
            phone.start(type, req.getParameter("number"),
                attempts == null ? 1 : Integer.parseInt(attempts));
            resp.setStatus(202);
        } catch (IllegalArgumentException e) {
            resp.sendError(400);
        } catch (IllegalStateException e) {
            resp.sendError(409);
        }
    }

    @Override
    protected void doGet(HttpServletRequest req,
                         HttpServletResponse resp) throws IOException {
        resp.setContentType("application/json");
        resp.getWriter().write("{\"state\":\"" + phone.state() + "\"}");
    }

    @Override
    protected void doDelete(HttpServletRequest req,
                            HttpServletResponse resp) {
        phone.stop();
        resp.setStatus(204);
    }

    @Override
    public void destroy() {
        phone.close();
    }
}
```
