**XPath** — язык запросов к элементам XML/HTML. В Selenium — поиск элементов на странице.

**Конструкции:**
* `/` — прямой потомок; `//` — любой уровень
* `@attr` — атрибут; `[n]` — n-й элемент; `[last()]` — последний
* Предикаты: `//input[@type='text']`, `[contains(@class,'btn')]`, `[starts-with(@id,'item-')]`, `[not(@disabled)]`

**Оси (направления обхода):**
* `child::` (по умолчанию), `parent::`
* `ancestor::`, `descendant::`
* `following::`, `following-sibling::`
* `preceding::`, `preceding-sibling::`
* `attribute::`, `self::`

**Примеры:**
* `//button[text()='Submit']`
* `//table//tr[td='John']/td[3]`
* `//div[@class='modal']//input`

Предпочитать относительные пути (`//`) и атрибуты `@id`, `@name`, `@data-testid`.

**Системные функции XPath** — встроенные функции для работы с узлами, числами, строками.

**Контекст и позиция:**
* `last()` — индекс последнего (`//tr[last()]`)
* `position()` — позиция узла (`//li[position()=1]`)
* `count(node-set)` — количество узлов

**Узлы:** `name()`, `local-name()`, `namespace-uri()`

**Boolean:** `boolean()`, `not()`, `true()`, `false()`, `lang('en')`

**Числа:** `number()`, `sum()`, `floor()`, `ceiling()`, `round()`

**Строки:** `string()`, `concat()`, `contains()`, `starts-with()`, `substring()`, `string-length()`, `normalize-space()`

**Прочие:** `id('element-id')` — по ID (нужен DTD)

В Selenium чаще всего: `last()`, `position()`, `count()`, `contains()`, `starts-with()`, `not()`.
