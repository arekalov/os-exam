## Слои Spring-приложения

- **Controller (`@RestController`)** — принимает HTTP-запросы, делегирует сервису, не содержит бизнес-логики
- **Service (`@Service`)** — бизнес-логика, правила предметной области, транзакции
- **Repository (`@Repository`)** — доступ к БД через Spring Data JPA или ручную реализацию

## Сервисный слой

Бизнес-логика оформляется как Spring-бин с `@Service`. Транзакции ставятся на уровне сервиса:

```java
@Service
public class OrderService {
    @Transactional
    public void placeOrder(Order order) {
        inventoryRepo.decrease(order.getItemId());
        orderRepo.save(order);
    }
}
```

## Взаимодействие с REST

Контроллер вызывает сервис, не реализует логику:

```java
@RestController
public class OrderController {
    @PostMapping("/orders")
    public void create(@RequestBody Order order) {
        orderService.placeOrder(order);
    }
}
```

## Взаимодействие с БД

Spring Data автоматически создаёт реализацию репозитория по именам методов:

```java
public interface OrderRepository extends JpaRepository<Order, Long> {
    List<Order> findByUserId(long userId);
}
```
