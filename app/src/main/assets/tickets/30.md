**Selenium** — автоматизация тестирования веб-приложений (клики, ввод, проверки).

**Архитектура:** Тест → WebDriver API → Browser Driver (ChromeDriver и др.) → Браузер.

**Компоненты:**
* **WebDriver** — API управления браузером
* **Selenium IDE** — запись/воспроизведение без кода
* **Selenium Grid** — распределённый запуск

**Основные команды WebDriver:**
* **Навигация:** `get(url)`, `getTitle()`, `navigate().back()/forward()/refresh()`
* **Поиск:** `findElement(By.id/name/xpath/cssSelector)`, `findElements`
* **Действия:** `click()`, `sendKeys()`, `clear()`, `getText()`, `getAttribute()`, `isDisplayed()`, `isEnabled()`, `isSelected()`
* **Окна/фреймы:** `switchTo().frame()`, `defaultContent()`, `switchTo().window()`

**Selenium IDE:** `open`, `type`, `click`, `verifyText` — те же действия, но в табличном формате.
