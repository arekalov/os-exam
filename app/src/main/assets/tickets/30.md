## JSSE и основные классы

**JSSE (Java Secure Socket Extension)** — средства Java для TLS: handshake, шифрование, проверка целостности и аутентификация.

- **SSLContext** — контекст TLS с параметрами соединения, менеджерами ключей и доверия; создаёт фабрики сокетов.
- **KeyManagerFactory** — создаёт менеджеры, выбирающие приватный ключ и цепочку сертификатов из keystore.
- **TrustManagerFactory** — создаёт менеджеры проверки сертификатов другой стороны на основе truststore.
- **SSLSocket** — защищённое соединение; **SSLServerSocket** — приём таких соединений на сервере.

## Порядок настройки

1. Серверу подготовить приватный ключ и цепочку сертификатов в keystore.
2. Клиенту настроить доверие к CA сервера либо конкретному самоподписанному сертификату.
3. Загрузить хранилища через `KeyStore`, настроить менеджеры и `SSLContext`.
4. Создать TLS-соединение; проверить сертификат и имя сервера.
5. Для **mTLS** дополнительно дать клиенту его ключ и сертификат, а серверу — доверие к издателю клиента. На `SSLServerSocket` включить `setNeedClientAuth(true)`.

Фрагмент для уже загруженных `keyStore`, `trustStore` и пароля приватного ключа `keyPassword`:

```java
var kmf = KeyManagerFactory.getInstance(
    KeyManagerFactory.getDefaultAlgorithm());
kmf.init(keyStore, keyPassword);
var tmf = TrustManagerFactory.getInstance(
    TrustManagerFactory.getDefaultAlgorithm());
tmf.init(trustStore);

var context = SSLContext.getInstance("TLS");
context.init(kmf.getKeyManagers(), tmf.getTrustManagers(),
             new SecureRandom());
```

На обычном клиенте без сертификата можно передать `null` вместо `kmf.getKeyManagers()`.

## HTTPS и проверка узла

Для HTTP используют `HttpClient` / `HttpsURLConnection`, а в серверном приложении обычно настраивают HTTPS-коннектор контейнера или Spring Boot.

Проверка сервера включает проверку цепочки доверия и соответствия имени узла сертификату. Для клиентского `SSLSocket` проверка имени по правилам HTTPS настраивается до handshake:

```java
var parameters = socket.getSSLParameters();
parameters.setEndpointIdentificationAlgorithm("HTTPS");
socket.setSSLParameters(parameters);
socket.startHandshake();
```

`socket` создаётся фабрикой контекста с именем целевого сервера.
