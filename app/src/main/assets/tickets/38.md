## Условие

Написать спецификацию REST API для управления кодом доступа домофона. API позволяет получать текущий код, добавлять цифры, выполнять команду подтверждения и удалять последнюю введённую цифру.

## Ресурсы и операции

* `GET /code`	- Получить текущий код	200 OK
* `PUT /code`	- Добавить цифру или выполнить команду	200 OK
* `DELETE /code`	- Удалить последнюю цифру	204 No Content

## Управление кодом доступа

Управление кодом доступа
Код вводится последовательно:
- `GET /code` — получить текущий введённый код.
- `PUT /code?newDigit=5` — добавить цифру 5.
- `PUT /code?executeCode=ENTER` — подтвердить введённый код.
- `DELETE /code` — удалить последнюю введённую цифру.
Если введённый код верен, домофон разрешает открытие двери.

### Ошибки
- `400 Bad Request` — некорректные параметры или команда.
- `500 Internal` Server Error — внутренняя ошибка сервера.

### YAML-спецификация
```yaml
openapi: 3.0.3

info:
  title: Intercom API
  version: 1.0.0
  description: REST API for intercom access code management

paths:
  /code:
    get:
      description: Get current code
      responses:
        '200':
          description: Current code
          content:
            application/json:
              schema:
                $ref: '#/components/schemas/Code'
        '500':
          description: Server error, try again later.

    put:
      description: Update current code (add new digit or execute command)
      parameters:
        - name: newDigit
          in: query
          description: New digit
          schema:
            type: integer
            minimum: 0
            maximum: 9
        - name: executeCode
          in: query
          description: Command to execute
          schema:
            type: string
            enum: [ENTER]
      responses:
        '200':
          description: Successful command execution
        '400':
          description: Invalid digit or command
        '500':
          description: Server error, try again later.

    delete:
      description: Delete last digit in code
      responses:
        '204':
          description: Successful deletion
        '500':
          description: Server error, try again later.

components:
  schemas:
    Code:
      type: object
      properties:
        currentCode:
          type: string
          example: "125"
```
