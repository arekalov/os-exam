## Условие

Написать спецификацию (URL-ы) веб-сервиса, реализующего систему управления домофоном.

## Ресурсы и операции

Основные ресурсы — домофон, код доступа, дверь, электронные ключи и вызовы. Формат данных — JSON.

| Метод и URL| 	Операция	| Успешный ответ| 
|----|----|---|
| GET | /intercom| 	Получить информацию о домофоне и его состоянии	| 200 OK| 
| GET | /intercom/code| 	Получить текущий код доступа	| 200 OK| 
| PUT | /intercom/code| 	Добавить цифру или выполнить команду ввода кода| 	200 OK| 
| DELETE | /intercom/code| 	Удалить последнюю введённую цифру	| 200 OK| 
| PUT | /intercom/door| 	Открыть или закрыть дверь	| 200 OK| 
| POST | /intercom/keys| 	Зарегистрировать электронный ключ	| 201 Created| 
| DELETE | /intercom/keys/{keyId}| 	Удалить электронный ключ	| 204 No Content| 
| POST | /intercom/calls | 	Позвонить жильцу	| 201 Created|

## Управление кодом доступа

Код доступа вводится последовательно. PUT добавляет цифру или выполняет специальную команду, например подтверждение введённого кода. DELETE удаляет последнюю введённую цифру.

Пример добавления цифры: `PUT /intercom/code?newDigit=5`

Пример выполнения команды: `PUT /intercom/code?executeCode=ENTER`

Пример удаления последней цифры: `DELETE /intercom/code`

Если введённый код верен, домофон разрешает открытие двери.

## Управление дверью

PUT /intercom/door изменяет состояние двери: OPEN — открыть, CLOSED — закрыть.

Пример запроса:
```json
PUT /intercom/door
Content-Type: application/json

{
    "state": "OPEN"
}
```

## Управление электронными ключами
POST /intercom/keys регистрирует новый электронный ключ.
```json
{
    "keyCode": "A1B2C3",
    "residentId": 15
}
```

Ответ: 201 Created.

DELETE /intercom/keys/10 удаляет ключ с идентификатором 10. После удаления ключ больше не может использоваться для открытия двери.

## Вызов жильца
POST /intercom/calls инициирует вызов жильца по его идентификатору.
```json
{
    "residentId": 15
}
```

## Ошибки
- `400 Bad Request` — некорректные параметры или команда.
- `401 Unauthorized` — пользователь не прошёл аутентификацию.
- `403 Forbidden` — недостаточно прав для выполнения операции.
- `404 Not Found` — ключ или жилец не найдены, команда не существует.
- `409 Conflict` — операция невозможна в текущем состоянии домофона.
- `500 Internal` Server Error — внутренняя ошибка сервера.

### YAML-спецификация
```yaml
openapi: 3.0.3

info:
  title: Intercom API
  version: 1.0.0
  description: REST API for intercom management

paths:
  /intercom/code:
    get:
      description: Get current code
      responses:
        '200':
          description: Current code
          content:
            application/json:
              schema:
                $ref: '#/components/schemas/Code'
        '500':
          description: Server error

    put:
      description: Add digit or execute code command
      parameters:
        - name: newDigit
          in: query
          description: Digit to add to the code
          schema:
            type: integer
            minimum: 0
            maximum: 9
        - name: executeCode
          in: query
          description: Command to execute
          schema:
            type: string
            enum: [ENTER]
      responses:
        '200':
          description: Command executed successfully
        '400':
          description: Invalid digit or command
        '404':
          description: Command not found
        '500':
          description: Server error

    delete:
      description: Delete last digit in code
      responses:
        '200':
          description: Digit deleted successfully
        '500':
          description: Server error

  /intercom/door:
    put:
      description: Open or close the door
      requestBody:
        required: true
        content:
          application/json:
            schema:
              $ref: '#/components/schemas/DoorCommand'
      responses:
        '200':
          description: Door state changed
        '403':
          description: Access denied
        '409':
          description: Door operation is unavailable
        '500':
          description: Server error

  /intercom/keys:
    post:
      description: Register a new electronic key
      requestBody:
        required: true
        content:
          application/json:
            schema:
              $ref: '#/components/schemas/Key'
      responses:
        '201':
          description: Key registered
        '400':
          description: Invalid key data
        '409':
          description: Key already exists

  /intercom/keys/{keyId}:
    delete:
      description: Delete an electronic key
      parameters:
        - name: keyId
          in: path
          required: true
          schema:
            type: integer
            format: int64
      responses:
        '204':
          description: Key deleted
        '404':
          description: Key not found

  /intercom/calls:
    post:
      description: Call a resident
      requestBody:
        required: true
        content:
          application/json:
            schema:
              $ref: '#/components/schemas/Call'
      responses:
        '201':
          description: Call initiated
        '404':
          description: Resident not found
        '409':
          description: Call cannot be initiated

components:
  schemas:
    Code:
      type: object
      properties:
        currentCode:
          type: string
          example: "125"

    DoorCommand:
      type: object
      required:
        - state
      properties:
        state:
          type: string
          enum: [OPEN, CLOSED]

    Key:
      type: object
      required:
        - keyCode
        - residentId
      properties:
        keyCode:
          type: string
          example: A1B2C3
        residentId:
          type: integer
          format: int64

    Call:
      type: object
      required:
        - residentId
      properties:
        residentId:
          type: integer
          format: int64
```
