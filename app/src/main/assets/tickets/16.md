В JAX-RS аннотации используются для связывания Java-классов и методов с URI и HTTP-методами. Благодаря им разработчику не нужно самостоятельно обрабатывать маршрутизацию HTTP-запросов.

### @Path, @GET, @POST, @PUT, @DELETE.
`@Path` — задаёт URI, по которому доступен ресурс или отдельный метод ресурса. Можно применить к классу (базовый URL) или к методу (дополнительный сегмент url)

```java
@Path("/users") // базовый URL
public class UserResource {

    @GET
    @Path("/{id}") // добавление идентификатора пользователя
    public User getUser(@PathParam("id") Long id) {
        return userService.findById(id);
    }
}

Также можно использовать шаблоны URI с ограничениями: `@Path("/{id: [0-9]+}")` - id только числовой
```
**HTTP-методы** - JAX-RS предоставляет аннотации, связывающие методы Java с HTTP-методами, каждая из которых определяет, какой HTTP-запрос должен обрабатываться соответствующим методом Java.

* `@GET`	-	Получение ресурса
* `@POST`	-	Создание ресурса или выполнение операции
* `@PUT`	-	Полное обновление ресурса
* `@DELETE`	-	Удаление ресурса
* `@PATCH`	-	Частичное обновление (поддерживается современными реализациями через соответствующую аннотацию)

```java
@Path("/users")
public class UserResource {

    @GET
    public List<User> getUsers() {
        return userService.findAll();
    }

    @POST
    public User createUser(User user) {
        return userService.save(user);
    }

    @PUT
    @Path("/{id}")
    public User updateUser(
        @PathParam("id") Long id,
        User user
    ) {
        return userService.update(id, user);
    }

    @DELETE
    @Path("/{id}")
    public void deleteUser(@PathParam("id") Long id) {
        userService.delete(id);
    }
}
```

### Аннотации для определения форматов данных @Produces, @Consumes.
`@Produces` — указывает, в каком формате сервер может возвращать данные клиенту, применяется к классу/отдельному методу

```java
@GET
@Produces(MediaType.APPLICATION_JSON) // Сервер возвращает данные в формате JSON.
public User getUser() {
    return new User(15, "Alex");
}
```

Можно указать несколько форматов `@Produces({
    MediaType.APPLICATION_JSON,
    MediaType.APPLICATION_XML
})`, тогда фактический формат будет выбираться на основе `Accept`

`@Consumes` — указывает, какие форматы входящих данных принимает метод или ресурс.

```java
@POST
@Consumes(MediaType.APPLICATION_JSON)
public User createUser(User user) {
    return userService.save(user);
}
```

### @PathParam, @QueryParam, @HeaderParam.
`@PathParam` — получает значение из переменной части URI, используется, когда нужно обратиться к конкретному ресурсу по идентификатору.

```java
@GETл
@Path("/users/{id}") // GET /users/15 -> id=15
public User getUser(@PathParam("id") Long id) {
    return userService.findById(id);
}
```

`@QueryParam` — получает значение из query string, которая располагается после символа ?, обычно для фильтрации, сортировки и пагинации

```java
@GET
@Path("/users") // GET /users?name=Alex&age=20
public List<User> searchUsers(
    @QueryParam("name") String name, // name = Alex
    @QueryParam("age") Integer age // age = 20
) {
    return userService.search(name, age);
}
```

`@HeaderParam` — получает значение из HTTP-заголовка запроса (токены авторизации, информация о типе клиента, языковые предпочтения, другие метаданных запроса)

```java
@GET
@Path("/profile") // Authorization: Bearer abc123
public String getProfile(
    @HeaderParam("Authorization") String token // token = Bearer abc123
) {
    return "Token: " + token;
}
```

### @MatrixParam, @FormParam.

`@MatrixParam` —  отображает матричный параметр HTTP-запроса на параметр
метода. Матричные параметры указываются после символа ; внутри отдельного сегмента URI, похож на @QueryParam, но тот относится ко всему запросу целиком, а matrix-параметр - внутри конкретного сегемента

```java
@GET
@Path("/users") // /users;active=true;role=admin
public List<User> getUsers(
    @MatrixParam("active") boolean active, // true
    @MatrixParam("role") String role // admin
) {
    return userService.filter(active, role);
}
```

**`@FormParam`** — получает значение из тела HTTP-запроса, переданного в формате HTML-формы `application/x-www-form-urlencoded`, используется для обработки данных с HTML-форм. Значения полей формы автоматически передаются в соответствующие параметры метода.

```java
@POST
@Path("/login")
@Consumes(MediaType.APPLICATION_FORM_URLENCODED)
public String login(
    @FormParam("username") String username,
    @FormParam("password") String password
) {
    return authService.login(username, password);
}
```

`@CookieParam` – отображает cookie на параметр метода.


### @DefaultValue.

`@DefaultValue` — задаёт значение параметра по умолчанию, если соответствующий параметр отсутствует в запросе.

```java
@GET
@Path("/users") // /users
public List<User> getUsers(
    @QueryParam("limit")
    @DefaultValue("10") int limit // limit = 10
) {
    return userService.findAll(limit);
}
```
