## JMS
**Java Message Service (JMS)** — стандарт промежуточного ПО для рассылки сообщений,
позволяющий приложениям, выполненным на платформе Java EE, создавать, посылать,
получать и читать сообщения.

## Компоненты JMS
Приложение JMS состоит из следующих частей.
* **Провайдер JMS** — система обмена сообщениями, реализующая интерфейсы
JMS и предоставляющая функции администрирования и управления. Реализация
платформы Java EE, поддерживающая полный профиль, включает провайдера JMS.
* **JMS-клиенты** — программы или компоненты Java, отправляющие и получающие
сообщения, в качестве них может выступать любой компонент приложения Java EE, а также Java SE.
* **Сообщения** — объекты, передающие информацию между клиентами JMS. Состоят из заголовка (JMSDestination, JMSMessageID, JMSTimestamp...), **Свойств** - пары  ключ-значение, Тело - содержит информацию о типе сообщения (TextMessage, BytesMessage, MapMessage, ObjectMessage, StreamMessage) и полезную нагрузку.
* **Администрируемые объекты** — объекты JMS, настроенные для использования клиентами. Два вида администрируемых объектов JMS — пункты назначения и фабрики соединений — описаны в Администрируемые объекты JMS. Администратор может создавать объекты, доступные всем приложениям, использующим конкретную установку сервера GlassFish. Альтернативно, разработчик может использовать аннотации для создания объектов, специфичных для конкретного приложения.
Всего 2 вида:
  * Connection Factory - создает соединения с брокером
  * Destination - предоставление физическом очереди или топика
