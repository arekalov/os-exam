---

## Условие

Дан Spring Data Rest репозиторий с 1 методом public, который наследует crudrepository. Сделать так, чтобы все методы паблик стали доступны.

## Решение

```java
@RepositoryRestResource(path = "cars", exported = true)
public interface CarRepository extends CrudRepository<Car, Long> {
    List<Car> findByBrand(@Param("brand") String brand);
}
```

`@RepositoryRestResource` настраивает публикацию репозитория через REST: `path = "cars"` задаёт адрес `/cars`, `exported = true` разрешает экспорт.

В `application.properties`:

```properties
spring.data.rest.detection-strategy=default
```

Стратегия `default` включает экспорт публичных репозиториев и репозиториев с `@RepositoryRestResource`, учитывая флаги `exported`. Для данного публичного репозитория становятся доступны стандартные CRUD-операции и объявленный поисковый метод, если их экспорт явно не запрещён.
