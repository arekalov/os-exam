## Условие

Реализовать сервис производства резиновых уточек на основе сервлетов. Сервис должен позволять создавать заказы на изготовление уточек по 3D-модели, задавать размеры одной уточки и количество экземпляров в партии, а также просматривать состояние заказов.

## REST API
- `POST /ducks/orders` — создать заказ. Тело запроса: width=10&height=8&depth=7&quantity=100.
- `GET /ducks/orders?id=1` — получить информацию о заказе.
- `GET /ducks/orders` — получить список всех заказов.
- `POST /ducks/orders/cancel`, тело id=1 — отменить заказ.

## Сервис управления заказами

`DuckOrderService` отвечает за создание, хранение, получение и отмену заказов. 

```java
public class DuckOrderService {
    private final Map<Long, DuckOrder> orders = new HashMap<>();
    private final AtomicLong nextId = new AtomicLong(1);

    public synchronized DuckOrder create(int size, int quantity) {
        if (size <= 0 || size > 50) {
            throw new IllegalArgumentException(
                "Size must be between 1 and 50 cm");
        }

        if (quantity <= 0 || quantity > 10_000) {
            throw new IllegalArgumentException(
                "Quantity must be between 1 and 10000");
        }

        long id = nextId.getAndIncrement();
        DuckOrder order = new DuckOrder(id, size, quantity);

        orders.put(id, order);
        return order;
    }

    public synchronized DuckOrder get(long id) {
        DuckOrder order = orders.get(id);
        if (order == null) {
            throw new NoSuchElementException("Order not found");
        }
        return order;
    }

    public synchronized List<DuckOrder> getAll() {
        return new ArrayList<>(orders.values());
    }

    public synchronized void cancel(long id) {
        DuckOrder order = get(id);

        if (!"CREATED".equals(order.getStatus())) {
            throw new IllegalStateException(
                "Only CREATED orders can be cancelled");
        }

        order.setStatus("CANCELLED");
    }
}
```

### Сервлет
Сервлет обрабатывает HTTP-запросы, получает параметры заказа, вызывает DuckOrderService и возвращает результат в JSON.

```java
@WebServlet("/ducks/orders/*")
public class DuckOrderServlet extends HttpServlet {

    private final DuckOrderService service = new DuckOrderService();

    @Override
    protected void doGet(HttpServletRequest req,
                         HttpServletResponse resp) throws IOException {
        String idParam = req.getParameter("id");

        try {
            if (idParam != null) {
                long id = Long.parseLong(idParam);
                respond(resp, service.get(id));
            } else {
                respond(resp, service.getAll());
            }
        } catch (NumberFormatException e) {
            resp.sendError(400, "Invalid order ID");
        } catch (NoSuchElementException e) {
            resp.sendError(404, e.getMessage());
        }
    }

    @Override
    protected void doPost(HttpServletRequest req,
                          HttpServletResponse resp) throws IOException {
        String path = req.getPathInfo();

        try {
            if ("/cancel".equals(path)) {
                long id = Long.parseLong(req.getParameter("id"));
                service.cancel(id);
                resp.setStatus(204);
                return;
            }

            if (path != null && !"/".equals(path)) {
                resp.sendError(404);
                return;
            }

            int size = Integer.parseInt(req.getParameter("size"));
            int quantity = Integer.parseInt(req.getParameter("quantity"));

            DuckOrder order = service.create(size, quantity);

            resp.setStatus(201);
            respond(resp, order);

        } catch (NumberFormatException e) {
            resp.sendError(400, "Invalid order parameters");
        } catch (IllegalArgumentException e) {
            resp.sendError(400, e.getMessage());
        } catch (NoSuchElementException e) {
            resp.sendError(404, e.getMessage());
        } catch (IllegalStateException e) {
            resp.sendError(409, e.getMessage());
        }
    }

    private void respond(HttpServletResponse resp, Object data)
            throws IOException {
        resp.setContentType("application/json");
        resp.setCharacterEncoding("UTF-8");
        resp.getWriter().write(toJson(data));
    }

    private String toJson(Object data) {
        if (data instanceof DuckOrder order) {
            return String.format(
                "{\"id\":%d,\"size\":%d,\"quantity\":%d,\"status\":\"%s\"}",
                order.getId(), order.getSize(),
                order.getQuantity(), order.getStatus()
            );
        }

        if (data instanceof List<?> list) {
            return list.stream()
                .map(this::toJson)
                .collect(Collectors.joining(",", "[", "]"));
        }

        return "{}";
    }
}
```
