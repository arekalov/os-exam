## Условие

Реализовать сервис производства резиновых уточек на основе сервлетов. Сервис должен позволять создавать заказы на изготовление уточек по 3D-модели, задавать размеры одной уточки и количество экземпляров в партии, а также просматривать состояние заказов.

## REST API
- `POST /ducks/orders` — создать заказ. Тело запроса: width=10&height=8&depth=7&quantity=100.
- `GET /ducks/orders?id=1` — получить информацию о заказе.
- `GET /ducks/orders` — получить список всех заказов.
- `POST /ducks/orders/cancel`, тело id=1 — отменить заказ.

### Модель заказа
`DuckOrder` хранит параметры заказа и его состояние.

```java
public class DuckOrder {
    private final long id;
    private final int size;
    private final int quantity;
    private String status;

    public DuckOrder(long id, int size, int quantity) {
        this.id = id;
        this.size = size;
        this.quantity = quantity;
        this.status = "CREATED";
    }

    public long getId() { return id; }
    public int getSize() { return size; }
    public int getQuantity() { return quantity; }
    public String getStatus() { return status; }

    public void setStatus(String status) {
        this.status = status;
    }
}
```

## Сервис управления заказами

`DuckOrderService` отвечает за создание, хранение, получение и отмену заказов. 

```java
public class DuckOrderService {
    private final Map<Long, DuckOrder> orders = new HashMap<>();
    private final AtomicLong nextId = new AtomicLong(1);

    public synchronized DuckOrder create(int size, int quantity) {
        if (size <= 0 || size > 50) {
            throw new IllegalArgumentException(
                "Size must be between 1 and 50 cm");
        }

        if (quantity <= 0 || quantity > 10_000) {
            throw new IllegalArgumentException(
                "Quantity must be between 1 and 10000");
        }

        long id = nextId.getAndIncrement();
        DuckOrder order = new DuckOrder(id, size, quantity);

        orders.put(id, order);
        return order;
    }

    public synchronized DuckOrder get(long id) {
        DuckOrder order = orders.get(id);
        if (order == null) {
            throw new NoSuchElementException("Order not found");
        }
        return order;
    }

    public synchronized List<DuckOrder> getAll() {
        return new ArrayList<>(orders.values());
    }

    public synchronized void cancel(long id) {
        DuckOrder order = get(id);

        if (!"CREATED".equals(order.getStatus())) {
            throw new IllegalStateException(
                "Only CREATED orders can be cancelled");
        }

        order.setStatus("CANCELLED");
    }
}
```
