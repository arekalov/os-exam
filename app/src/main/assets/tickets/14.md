## CDI, IoC, DI в Spring — что такое инверсия управления, внедрение зависимостей, как реализовано в Spring

**IoC (Inversion of Control)** — принцип, при котором управление созданием и жизненным циклом объектов передаётся контейнеру, а не программисту.  Вместо new MyService() нужно объявить зависимость, а Spring создаст ее экземпляр и внедрит его. Контейнер управляет жизненным циклом бинов. IoC — более широкое понятие, DI — один из способов его реализации.

**DI (Dependency Injection)** — основной способ реализации IoC. Зависимости передаются объекту извне, а не создаются им самим. В Spring реализуется через аннотации (`@Autowired, @Inject`), конструкторы (рекомендуемый способ для final полей), сеттеры или поля. Spring автоматически находит подходящий бин по типу (или имени через` @Qualifier`). Поддерживаются циклические зависимости (решаются через прокси или кэширование). 

**CDI (Contexts and Dependency Injection)** — стандарт Java EE/Jakarta EE (JSR-365) для реализации DI и управления контекстами, который Spring поддерживает наравне со своими аннотациями. 

IoC-контейнер Spring — **ApplicationContext**.

В Spring реализуется через:
- `@Component`, `@Service`, `@Repository` — объявление бинов
- `@Autowired` — внедрение зависимостей

### Примеры DI в Spring 
* Конструктор (рекомендуемый способ для final полей)
```java
@Service
public class UserService {
    private final UserRepository userRepository;
    private final EmailService emailService;
    
    // @Autowired не обязателен, если есть один конструктор (Spring 4.3+)
    public UserService(UserRepository userRepository, EmailService emailService) {
        this.userRepository = userRepository;
        this.emailService = emailService;
    }
}
```
* Сеттер-инъекция (для опциональных зависимостей)
```java
@Service
public class ReportService {
    private CacheManager cacheManager;
    
    @Autowired(required = false)  // Может быть null
    public void setCacheManager(CacheManager cacheManager) {
        this.cacheManager = cacheManager;
    }
}
```
* Использование CDI-аннотаций
```java
import javax.inject.Inject;
import javax.inject.Named;
import javax.inject.Singleton;

@Named  // Альтернатива @Component
@Singleton  // Альтернатива @Scope("singleton")
public class ShoppingCart {
    
    @Inject  // Альтернатива @Autowired
    private ProductRepository productRepository;
    
    @Inject
    @Named("taxCalculator")  // Альтернатива @Qualifier
    private TaxCalculator taxCalculator;
}
```
