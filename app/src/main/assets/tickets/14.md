## 2 Phase-commit (2PC)

**2PC** - классический, тяжеловесный механизм распределенных транзакций, основанный на протоколе «все или ничего». Сначала управляющий сервис (координатор) опрашивает всех участников, готовы ли они выполнить операцию (фаза Prepare). Если все подтверждают готовность, координатор дает команду на фиксацию (Commit). Если хотя бы один ответил отказом — дается команда откатить изменения (Rollback). 2PC требует, чтобы все участники (сервисы, базы данных) поддерживали этот протокол и были доступны синхронно, что создает «блокировки» и резко снижает общую доступность (availability) системы, что критично для современных распределенных архитектур и микросервисов. Кроме того, многие современные NoSQL базы данных и брокеры сообщений просто не поддерживают 2PC. Как правило, 2PC используется для мгновенный транзакция (например в одной сети)

## Saga
Вместо глобальной блокировки, Saga разбивает длинную транзакцию на последовательность локальных,коротких шагов. Для каждого шага, который уже был выполнен, разработчик определяет компенсирующеедействие («откат»). Если на каком-то этапе произошла ошибка, запускается цепочка компенсаций,которая отменяет результаты всех ранее успешно выполненных шагов. Saga - основной способ обеспечения консистентности данных в распределенных системах на базе BPMN.
В Camunda механизм реализации - **Компенсирующие события** (Compensation Events), которые вешаются на каждый потенциально опасный шаг (Списать деньги) и содержат логику отметы (Вернуть деньги). Как правило, Saga используется для длительных транзакция, например, с участием внешних систем

## Поддержка JTA
**JTA (Java Transaction API)** — спецификация Java для управления распределёнными транзакциями, реализующая стандарт X/Open XA. Camunda 7 предоставляет интеграцию с JTA для работы в managed-средах Java EE/Spring-приложеней для использования в методах, где бизнес-логика и движок работают в общей транзакции:
* Автоматическое включение JDBC-операций движка в глобальную JTA-транзакцию
* Совместное использование транзакции между бизнес-логикой приложения и Camunda API
* Поддержка встроенных конфигураций для Wildfly, JBoss EAP, WebSphere, WebLogic
