## Табличные пространства

**Табличное пространство** (tablespace) — именованное место на файловой системе, где PostgreSQL хранит файлы объектов БД (таблицы, индексы). Позволяет размещать данные на разных дисках для управления производительностью и объёмом.

### Встроенные табличные пространства
* **pg_default** — используется по умолчанию для всех объектов (каталог `PGDATA/base/`).
* **pg_global** — для общих объектов кластера (`PGDATA/global/`).

### Создание и использование
```sql
-- Создание (суперпользователь, каталог должен существовать и принадлежать postgres):
CREATE TABLESPACE fast_disk LOCATION '/mnt/ssd/pgdata';

-- Создание БД в табличном пространстве:
CREATE DATABASE mydb TABLESPACE fast_disk;

-- Создание таблицы в табличном пространстве:
CREATE TABLE orders (...) TABLESPACE fast_disk;

-- Перемещение таблицы:
ALTER TABLE orders SET TABLESPACE fast_disk;

-- Просмотр:
SELECT spcname, pg_tablespace_location(oid) FROM pg_tablespace;
\db   -- в psql
```

### Назначение
* Разместить горячие таблицы на быстром SSD, архивные — на медленном HDD.
* Вынести большие индексы на отдельный диск.
* Обойти ограничения на размер файловой системы — данные распределяются по нескольким точкам монтирования.

В `PGDATA/pg_tblspc/` создаются симлинки на реальные каталоги. Удалить табличное пространство можно только если оно пустое: `DROP TABLESPACE fast_disk;`
