## Файловая структура и конфигурация PostgreSQL
Все данные кластера хранятся в каталоге по пути PGDATA, внутри которого:
* `global` – содержит таблицы уровня кластера
(pg_database).
* `pg_wal` – директория с WAL-файлами.
* `pg_xact` – директория с данными о коммитах
транзакций (CLOG).
* `base` – файлы данных базы данных кластер, названные по OID базы из pg_database.  При превышении 1 ГБ файл разбивается на сегменты: `relfilenode.1, .2` и т.д.
  
### Конфигурация
Стандартный путь, по которому располагаются
конфигурационные файлы: `/etc/postgresql/версия/main/`
* `postgresql.conf` — базовый файл для хранения настроек, представляющий собой набор параметров имя-значение (`shared_buffers = 128MB`) и определяющий значения для всего кластера
* `postgresql.auto.conf` — динамически изменяемые настройки (через `ALTER SYSTEM`).
* `pg_hba.conf` — конфигурация подключений к БД.
* `pg_ident.conf` — файл отображения имен.
