## PostgreSQL, создание Базы Данных

Создание базы данных выполняется командой `CREATE DATABASE (name) WITH (options)` (или утилитой `createdb`). Физически операция клонирует существующую базу-шаблон (template1 по умолчанию, можно использовать другую с помощью опции `TEMPLATE`, при этом к ней не должно быть подключений других пользователей), т.е. все объекты, созданные в template1 (расширения, таблицы), автоматически появятся во всех новых БД. Для создания чистой БД без пользовательских объектов нужно указать `TEMPLATE template0`.Для создания БД пользователь должен быль суперпользователем или иметь роль `CREATEDB`

**Важные параметры**: `OWNER` задает владельца, `ENCODING` — кодировку (должна совместима с локалью), `LC_COLLATE` и `LC_CTYPE` определяют правила сортировки и классификации символов, которые нельзя изменить после создания БД . `TABLESPACE` задает табличное пространство по умолчанию. `CONNECTION LIMIT` ограничивает число подключений. STRATEGY = WAL_LOG (по умолчанию) или `FILE_COPY` определяет метод копирования данных (последний полезен для очень больших шаблонов, но требует дополнительных контрольных точек)
