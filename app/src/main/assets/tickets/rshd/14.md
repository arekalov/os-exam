## Процессы, обеспечивающие работу PostgreSQL

**Postmaster** — родительский процесс, представляет сервер postgresql, отвечает за запуск и остановку postgresql, управляет данными одного кластера БД. При каждом новом подключении создает серверный процесс для обслуживания клиента до его отключения.

### Фоновые процессы 
* **Checkpointer** — периодически пишет все изменённые буферы из shared buffers на диск, обновляет контрольную точку (**checkpoint**). Снижает время восстановления после сбоя.
* **Background writer** — Периодически записывает измененные («грязные») страницы из SB на диск в файлы данных. Помечает записанние страницы «чистыми». Работает непрерывно, облегчает работу процесса checkpointer. Настраивается в конфиге через `bgwriter_delay`
* **WAL writer** — сбрасывает WAL-буферы в файлы журнала предзаписи (`pg_wal`). Периодичность задаётся параметром `wal_writer_delay`.
* **Autovacuum worker** — несколько процессов, которые запускают `VACUUM` и `ANALYZE` автоматически, чтобы избежать раздувания таблиц и обновить статистику.
* **Stats collector** — собирает статистику обращений к таблицам, индексам, * функциям; статистика хранится в промежуточных файлах `pg_stat_*` и через них используется другими процессами.
* **Logging collector** — записывает сообщения, отправленные в stderr, в лог-файлы. Для работы нужен установленный параметр `logging_collector`.
* **Archiver** - копирует созданные wal-файлы в указанное место, по умолчанию выключен
* **WAL sender / WAL receiver** — для потоковой репликации (основной и реплика).
