## Табличные пространства. Назначение. Организация и настройка
**Табличное пространство** (TABLESPACE) — это именованное место на диске для хранения объектов баз данных вне стандартного каталога PGDATA/base. Позволяет распределять нагрузку на дисковую подсистему: например, разместить часто используемые индексы на быстрых SSD, а архивные таблицы — на медленных HDD . Также это упрощает управление дисковым пространством и восстановление после сбоев (media recovery). Создается командой `CREATE TABLESPACE name LOCATION '/some/path'`, при этом каталог должен принадлежать пользователю postgres. `$PGDATA/pg_tblspc` содержит символические ссылки на директории внешних табличных пространств. В каталоге `pg_tablespace` можно посмотреть все табличные пространства. Табличные пространства можно задать для таблиц, индексов, последовательностей,
представлений: `CREATE TABLE STUDENT (
id integer NOT NULL
) TABLESPACE newTablespace;`

Стандартные табличные пространства:
* `pg_default` — соответствует директории base в PGDATA, здесь хранятся файлы данных, соответствующие объектам БД.
* `pg_global` — соответствует директории global в
PGDATA, здесь хранятся pg_database, pg_authid, pg_tablespace, некотоые
другие каталоги и индексы.
