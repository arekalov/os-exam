title: Выбор тестового покрытия с помощью таблицы решений.
---

**Таблица решений (Decision Table)** — техника для систем с комбинациями условий и действий. Каждый столбец — одно правило: набор условий и ожидаемых действий.

**Структура:**
* **Условия (Conditions)** — входные факторы (Y/N, T/F)
* **Действия (Actions)** — реакции системы
* **Правила (Rules)** — столбцы с комбинациями условий → действия

**Шаги:** определить условия → определить действия → построить таблицу → упростить (объединить правила с «—» / don't care) → по одному тесту на правило.

**Плюсы:** полное покрытие бизнес-правил, наглядность, выявление противоречий в требованиях.
**Минус:** при n условиях — до 2^n правил; нужно упрощение или попарное тестирование.
