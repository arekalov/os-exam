## Файловая структура PostgreSQL

Все данные кластера хранятся в каталоге **PGDATA** (обычно `/var/lib/postgresql/<version>/main`).

### Структура PGDATA
* **base/** — подкаталог для каждой БД (имя = OID базы). Внутри — файлы сегментов таблиц и индексов по 1 ГБ.
* **global/** — общие для кластера объекты: `pg_database`, `pg_authid` и др.
* **pg_wal/** — файлы журнала предзаписи WAL (сегменты по 16 МБ).
* **pg_tblspc/** — симлинки на каталоги пользовательских табличных пространств.
* **pg_log/** / **log/** — текстовые журналы сервера.
* **PG_VERSION** — версия кластера.
* **postmaster.pid** — PID postmaster'а, удаляется при остановке сервера.

Каждая таблица хранится в трёх файлах: основной (`<oid>`), карта свободного пространства (`<oid>_fsm`), карта видимости (`<oid>_vm`).

### Файлы конфигурации

**postgresql.conf** — основной файл настроек: память (`shared_buffers`, `work_mem`), WAL (`wal_level`), соединения (`max_connections`), логирование. Перечитывается без перезапуска: `SELECT pg_reload_conf();`

**pg_hba.conf** — правила клиентской аутентификации (Host-Based Authentication). Строки вида `TYPE DATABASE USER ADDRESS METHOD`, проверяются сверху вниз, применяется первое совпадение. Методы: `trust`, `peer`, `md5`, `scram-sha-256`.

**pg_ident.conf** — маппинг системных пользователей ОС на роли PostgreSQL, используется при методах `ident` / `peer`.
