### Понятие ресурсного класса.
**Ресурсный класс** — Java-класс, который представляет ресурс REST API и содержит методы для обработки HTTP-запросов к нему, основа приложения на JAX-RS. Обычно содержит:
* аннотацию `@Path`, определяющую URI;
* методы с аннотациями HTTP-методов;
* параметры для получения данных из запроса;
* логику формирования HTTP-ответов.

```java
@Path("/users")
public class UserResource {

    @GET
    public List<User> getUsers() {
        return userService.findAll();
    }
}
```

### Описание URI с помощью @Path.
Аннотация `@Path` определяет URI, по которому доступен ресурс или отдельный обработчик, применяется на уровне класса (базовый URL) и метода (вложенные сегменты). Также 

### Обработчики HTTP-запросов.
**Обработчик HTTP-запроса** — метод ресурсного класса, вызываемый при поступлении запроса с соответствующим HTTP-методом и URI, обрабатывается `@GET/@POST/@PUT/@DELETE`

### Параметры методов.
Методы ресурсных классов могут принимать параметры, извлекаемые из различных частей HTTP-запроса  и автоматически педеваемые в метод:
* `@PathParam`	- URI	
* `@QueryParam`	- Строка запроса
* `@HeaderParam` - HTTP-заголовок	
* `@MatrixParam` - Матричный параметр URI
* `@FormPara`	- Данные HTML-формы

### Формирование HTTP-ответов.
JAX-RS позволяет возвращать из обработчиков обычные Java-объекты или использовать специальный класс `Response` для полного контроля над HTTP-ответом, позволяющий задавать:
- HTTP-код состояния;
- тело ответа;
- HTTP-заголовки;
- тип передаваемого содержимого.

```java
@POST
public Response createUser(User user) {
    User created = userService.save(user);

    return Response
        .status(Response.Status.CREATED) // 201
        .entity(created)
        .build();
}
```

### Сериализация и десериализация данных.
Для обмена данными между Java-приложением и клиентом JAX-RS использует механизмы сериализации и десериализации.

**Сериализация** — преобразование Java-объекта в формат передачи данных, например JSON или XML. Для этого используется компонент `MessageBodyReader`, который читает тело запроса и преобразует его в Java-объект.

**Десериализация** — обратное преобразование полученных данных в Java-объект. Для этого используется компонент `MessageBodyWriter`, который преобразует Java-объект в тело HTTP-ответа

### Примеры описания RESTful-ресурсов.
```java
public class Product {
    public Long id;
    public String name;
    public double price;
}

@Path("/products")
@Produces(MediaType.APPLICATION_JSON)
@Consumes(MediaType.APPLICATION_JSON)
public class ProductResource {

    @GET
    public List<Product> getProducts() {
        return productService.findAll();
    }

    @GET
    @Path("/{id}")
    public Product getProduct(
        @PathParam("id") Long id
    ) {
        return productService.findById(id);
    }

    @POST
    public Response createProduct(Product product) {
        Product created = productService.save(product);

        return Response
            .status(Response.Status.CREATED)
            .entity(created)
            .build();
    }

    @DELETE
    @Path("/{id}")
    public Response deleteProduct(
        @PathParam("id") Long id
    ) {
        productService.delete(id);
        return Response.noContent().build();
    }
}
```
