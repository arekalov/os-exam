## Что такое бизнес-логика

Бизнес-логика — уровень приложения, отвечающий за реализацию предметной области.

- Формирует основную вычислительную нагрузку
- Сложна в проектировании
- Обычно многопоточная
- Часто распределённая — размазана по набору однородных или неоднородных узлов

## Место в архитектуре

Находится между:
- **Снизу** — инфраструктурный уровень (например, уровень доступа к БД)
- **Сверху** — сервисный уровень (например, REST API)

## Взаимодействие с другими уровнями

- **Сервисный уровень (REST API)** — принимает запросы извне и передаёт их в бизнес-логику
- **Бизнес-логика** — обрабатывает запросы, реализует правила предметной области
- **Инфраструктурный уровень (БД)** — хранит и предоставляет данные по запросу бизнес-логики

## Особенности реализации

- При разработке часто используется **компонентный подход**
- Распределённая обработка — логика может быть размазана по нескольким узлам
- Многопоточность — несколько запросов обрабатываются параллельно
- Использует CDI/IoC для управления зависимостями
- Использует менеджеры транзакций для обеспечения целостности данных
- Использует политики безопасности для разграничения доступа
