## Аннотации контроллера и маршрутизации

- **`@Controller`** — регистрирует Spring MVC-контроллер. Для возврата тела ответа применяется `@ResponseBody`.
- **`@RestController`** — объединяет `@Controller` и `@ResponseBody` для всех методов класса.
- **`@RequestMapping`** — задаёт путь и условия выбора обработчика: `method`, `params`, `headers`, `consumes`, `produces`. Путь класса дополняется путём метода.
- **`@GetMapping`, `@PostMapping`, `@PutMapping`, `@PatchMapping`, `@DeleteMapping`** — сокращения `@RequestMapping` для соответствующих HTTP-методов.

## Параметры и тело сообщения

- **`@PathVariable`** — значение из шаблона пути: `/users/{id}`.
- **`@RequestParam`** — параметр запроса или формы; поддерживает `required` и `defaultValue`.
- **`@RequestHeader`** — значение HTTP-заголовка.
- **`@RequestBody`** — десериализация тела запроса в объект.
- **`@ResponseBody`** — сериализация результата метода в тело ответа.
- **`@ResponseStatus`** — установка HTTP-статуса ответа.

```java
@RestController
@RequestMapping("/users")
public class UserController {
    private final UserService service;

    public UserController(UserService service) {
        this.service = service;
    }

    @GetMapping("/{id}")
    public User get(@PathVariable("id") long id) {
        return service.findById(id);
    }

    @PostMapping
    @ResponseStatus(HttpStatus.CREATED)
    public User create(@RequestBody User user) {
        return service.create(user);
    }
}
```

## Обработка исключений

**`@ExceptionHandler`** связывает исключение с методом обработки. Внутри контроллера действует локально; **`@ControllerAdvice`** распространяет обработчики на несколько контроллеров. **`@RestControllerAdvice`** дополнительно включает `@ResponseBody`.

```java
@RestControllerAdvice
public class ErrorHandler {
    @ExceptionHandler(NoSuchElementException.class)
    @ResponseStatus(HttpStatus.NOT_FOUND)
    public Map<String, String> notFound() {
        return Map.of("error", "User not found");
    }
}
```
