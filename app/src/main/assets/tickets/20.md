title: Fuzzy testing (Фаззинг). Типы фаззинга.
---

**Fuzzy testing (фаззинг)** — техника динамического тестирования, при которой в программу подают большое количество **случайных, некорректных или неожиданных входных данных** с целью вызвать сбой, зависание, утечку памяти или небезопасное поведение. Особенно эффективен для поиска уязвимостей в парсерах, сетевых протоколах, API и обработчиках пользовательского ввода.

**Цели фаззинга:**
* обнаружение крашей и необработанных исключений
* поиск уязвимостей (переполнение буфера, injection, DoS)
* проверка устойчивости к некорректным данным

**Типы фаззинга по знанию системы:**
* **Black-box (слепой)** — тестировщик не знает внутреннюю структуру; генерируются случайные входные данные
* **White-box (с подсказками)** — используется информация о коде, протоколе, формате данных для более «умной» генерации
* **Gray-box** — частичное знание системы (спецификация API, схема сообщений)

**Типы по способу генерации данных:**
* **Dumb fuzzing (глупый)** — полностью случайные байты/строки без учёта формата
* **Smart fuzzing (умный)** — генерация с учётом структуры протокола, формата файла, типов полей
* **Mutation-based (мутационный)** — берёт валидный вход и **мутирует** его (меняет байты, обрезает, дублирует)
* **Generation-based (генеративный)** — строит входные данные **с нуля** по модели/грамматике/спецификации

**Типы по степени автоматизации:**
* **Manual fuzzing** — ручной ввод нестандартных значений
* **Automated fuzzing** — инструменты генерируют и отправляют тысячи/миллионы вариантов

**Типичный процесс:**
1. Определить точку входа (API, файл, сокет, форма)
2. Сгенерировать или мутировать входные данные
3. Подать данные в систему
4. Мониторить: crash, hang, memory leak, аномальный ответ
5. Минимизировать воспроизводимый тест-кейс и завести дефект

**Примеры инструментов:** AFL (American Fuzzy Lop), libFuzzer, Honggfuzz, Peach Fuzzer, OSS-Fuzz.

**Отличие от других видов тестирования:**
* **Функциональное** — проверка корректной работы на ожидаемых данных
* **Негативное** — осознанно выбранные неверные сценарии
* **Фаззинг** — массовая автоматическая подача случайных/мутированных данных для поиска неизвестных дефектов
