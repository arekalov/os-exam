## Cron
**Cron** — планировщик задач, используемый для выполнения задач в фоновом режиме в указанное время в Linux

**Crontab** - команда, используемая для управления планировщиком Cron. Команда crontab создает файл crontab, содержащий команды и инструкции для запуска демона cron, каждая запись в нем состоит из 6 полей в след. формате: `minute(s) hour(s) day(s) month(s) weekday(s) command(s)`
### Параметры crontab
* `-l` - вывести содержимое текущего файла расписания
* `-r` - удаление текущего файла расписания
* `-e` - редактирования текущего файла расписания

## Архитектура
**Cron** — демон, запускаемый при старте системы, который просыпается каждую минуту для проверки конфигурационных файлов crontab и запуска заданий, чьё временное выражение совпадает с текущим системным временем. Основные компоненты — сам демон crond, набор правил crontab для каждого пользователя и системные папки (`/etc/crontab, /etc/cron.d/*`), причём выполнение заданий никогда не перекрывается, т.е если предыдущий запуск не завершился, следующий не начнётся.

## Интеграция в ОС
В большинстве UNIX-подобных ОС (Linux, macOS) Cron интегрирован на уровне системного сервиса (демон crond), который автоматически стартует через init system (System V, systemd) и может управляться стандартными командами (`systemctl start/stop/restart cron`). Кроме того, система предоставляет каталоги для периодических скриптов (`/etc/cron.hourly, cron.daily` и т.д.), запускаемые через системный crontab командой `run-parts`, и пользовательские crontab -e для изолированного планирования задач от имени конкретного пользователя.

## Способы конфигурации
Основной способ — редактирование пользовательского crontab через команду crontab -e, либо создание/редактирование системных файлов напрямую (/etc/crontab для системных заданий с указанием пользователя-исполнителя, а также отдельные файлы в /etc/cron.d/). Также можно использовать готовые сценарии в cron.hourly/daily/weekly/monthly (положить туда исполняемый файл) или переменные окружения внутри crontab (например, MAILTO, PATH, SHELL) для управления средой выполнения.

## синтаксис Cron Expression
Классический Cron Expression (в UNIX crontab) состоит из 5 полей, разделенных пробелом, которые задают минуты, часы, день месяца, месяц и день недели. Поддерживаются специальные символы: * (любое значение), */N (каждые N единиц), N-M (диапазон), A,B,C (список значений) — например, 0 8 * * 1 означает «каждый понедельник в 8:00». Дополнительно можно использовать нестандартные макросы (@daily @midnight, @hourly), а в расширенных реализациях (Quartz, Spring) добавляется 6-е поле для секунд и 7-е для года.
