### Назначение спецификации OpenAPI.
**OpenAPI Specification** (OAS) — стандарт описания RESTful API в машиночитаемом формате JSON или YAML, позволяет описать интерфейс сервиса без необходимости изучать его исходный код, а также автоматически генерировать клиентский код. Содержит:
* доступные URI и HTTP-методы;
* параметры запросов;
* форматы входных и выходных данных;
* возможные HTTP-коды ответов;
* схемы данных;
* способы аутентификации.

### Структура OpenAPI-документа.
OpenAPI-документ обычно создаётся в формате YAML или JSON, основные элементы:
* openapi -	Версия спецификации OpenAPI
* info -	Название, версия и описание API
* servers -	Адреса серверов API
* paths -	Доступные пути и операции
* components -	Повторно используемые схемы, параметры и другие элементы
* security -	Требования к аутентификации и авторизации
* tags -	Группировка операций

### Описание путей, методов, параметров и ответов.
В OpenAPI каждый путь (path) соответствует URI ресурса, а внутри него описываются поддерживаемые HTTP-методы. Для описания структур данных используются схемы `schemas` (integer, char, string). Пример:

```yaml
paths:
  /users/{id}:
    get:
      summary: Получить пользователя // краткое описание операции
      parameters: // параметры запроса
        - name: id
          in: path
          required: true
          schema:
            type: integer
      responses: // возможные ответы сервера
        '200':
          description: Пользователь найден
        '404':
          description: Пользователь не найден
```

### Swagger Editor.
**Swagger** — набор инструментов для работы со спецификацией OpenAPI: её создания, редактирования, визуализации и генерации кода.

**Swagger Editor** — инструмент для создания и редактирования OpenAPI-документов. Возможности:
- редактирование YAML и JSON;
- проверка синтаксиса;
- обнаружение ошибок спецификации;
- предварительный просмотр документации.

### Swagger UI
Swagger UI — инструмент для отображения OpenAPI-спецификации в виде интерактивной веб-документации. Возможности:
- просмотр доступных endpoint;
- изучение параметров и ответов;
- отправка тестовых HTTP-запросов через интерфейс;
- просмотр результатов выполнения запросов.

### Swagger Codegen
**Swagger Codegen** — инструмент автоматической генерации исходного кода на основе OpenAPI-спецификации. Позволяет генерировать:
- клиентские библиотеки для обращения к API;
- серверные заглушки (skeleton);
- модели данных;
- документацию.

### Автоматическая генерация документации и клиентского кода

OpenAPI позволяет автоматизировать часть процесса разработки RESTful-сервисов. На основе разработанной OpenAPI-спецификации:
* Swagger UI - Интерактивная документация и тестирование
* Swagger Codegen - Генерация клиентов и серверного кода
