## Профили запуска Spring (Spring Boot Profiles) — что такое профили, зачем нужны, как настраиваются, применение для dev/prod окружений

**Профили** (Spring Boot Profiles) — механизм изоляции конфигураций для разных сред (dev, test, prod). Например, в dev используется встроенная H2 с автогенерацией схемы, а в prod — PostgreSQL через JNDI или пул соединений. Без профилей пришлось бы вручную комментировать/раскомментировать конфигурацию или использовать системные переменные.

**Настройка** происходит через файлы `application-{profile}.properties` (или YAML). **Активация**: spring.profiles.active=prod через аргумент JVM (-Dspring.profiles.active=prod), переменную окружения `SPRING_PROFILES_ACTIVE` или программно. Также можно использовать` @Profile("dev")` на бинах. Для тестов — @ActiveProfiles("test"). В коде доступ к активным профилям через Environment. Это даёт гибкость: один JAR-файл работает везде.

Пример профиля (application-dev.properties (разработка)):
```yaml
# Локальная H2 база данных
spring.datasource.url=jdbc:h2:mem:testdb
spring.datasource.driverClassName=org.h2.Driver
spring.datasource.username=sa
spring.datasource.password=

# Автосоздание схемы при каждом запуске
spring.jpa.hibernate.ddl-auto=create-drop

# Включение консоли H2
spring.h2.console.enabled=true

# Логирование на уровне DEBUG
logging.level.com.myapp=DEBUG

# Свойства для отладки
myapp.feature.flag=true
```
